# Participant Flow & Motivation Mapping · 成交者流与动机映射

## 核心理念

> **股票涨跌没有公式。价格只是买卖双方在某一刻的成交。**
>
> 买方和卖方各自来自哪里？他们的意愿有多强？他们的逻辑在什么地方发生了变化？
>
> 这种动机的变化是经验性的，隐藏在过去的交易历史里。
>
> 每一只股票的价格，都是由一群**结构相对固定的交易者**共同构成的；而他们的动机，会随着每天不同信息的输入此消彼长。

本层是**第一性原理层**——在任何其他方法论（戴维斯双击、Serenity、Capex 轮动、Gamma 结构等）之前，先回答以下问题。

---

## 1. 参与者组成矩阵

对任何标的，先绘制参与者画像：

| 参与者类型 | 典型占比 | 信念强度 | 持仓久期 | 动机触发 |
|---|---|---|---|---|
| **产业资本/创始人** | 5-30% | 极高 | 数年 | 锁定期到期、控制权事件、个人流动性需求 |
| **主动管理基金** | 20-50% | 中-高 | 季-年 | 财报推翻/确认逻辑、行业轮动、申赎压力 |
| **被动/指数 ETF** | 5-20% | 机械 | 无限 | 指数调仓、资金流入/流出、再平衡日 |
| **散户** | 10-30% | 低-中 | 天-周 | 动量、热榜、社交媒体 FOMO/恐慌、券商评级 |
| **做空者** | 1-20% | 高（空方） | 周-月 | 催化事件、逻辑证伪、融券成本警示 |
| **算法/做市商** | — | 中性 | 日内 | 订单流不平衡、波动率、多空 Gamma |
| **回购/公司自身** | 0-5% | 高 | 持续 | 授权窗口、估值感知、反稀释 |

### 关键问题

- 这只标的的**边际买家**是谁？（谁在当下最可能出手买入？）
- 这只标的的**边际卖家**是谁？（谁在当下最可能出手卖出？）
- 他们各自的**信念强度**如何？（产业资本有极高信念不会轻易卖，散户一跌就退）
- 什么**新信息**能改变其中一方的逻辑？

## 2. 动机变化信号

每类参与者的动机变化可通过以下信号识别：

### 机构流变化

| 信号 | 数据源 | 解读 |
|---|---|---|
| 机构持股数大幅上升/下降 | `shareholder_top` / 13F 季报 | 聪明钱在积/减持 |
| Broker queue 集中变化（港股） | `broker_holding` | 谁在通过哪个席位收/出货 |
| 申赎流量（基金/ETF） | 公开基金数据 | 被动资金被迫买入/卖出 |
| 评级/目标价调整 | `institution_rating` | 机构逻辑变化，引发 mandate 交易 |
| 大量 block trade（大宗交易） | 媒体/公开披露 | 机构在 OTC 换手，不直接影响盘口 |

### 零售流变化

| 信号 | 数据源 | 解读 |
|---|---|---|
| 交易量突变 | K-line volume | 关注度涌入/逃逸 |
| 社交媒体/论坛密度 | Web/X 监测 | 叙事形成/破灭 |
| Call 期权交易量激增 | `option_volume` | 散户+对冲买 call → 做市商对冲 |
| 小单买入占比异常 | `trade_stats` | 散户在主导方向 |

### 空方流变化

| 信号 | 数据源 | 解读 |
|---|---|---|
| 做空比例上升/下降 | `short_positions` | 空方在增仓还是撤离 |
| 日内大单卖压→价格上涨 | `capital_flow` + `trades` | 空头在被挤压 |
| 融券成本跳升 | 券商/公开数据 | 空头极度拥挤→潜在 squeeze |
| Positive catalyst+高short% | 财报/公告 | 最经典 squeeze 场景 |

### 做市商流变化

| 信号 | 数据源 | 解读 |
|---|---|---|
| Gamma 翻转负→正 | `option_chain_info_by_date` | 做市商从卖家变买家（或反之） |
| 期权成交量/OI 异常 | `option_volume_daily` | 结构性 Gamma/Delta 移仓 |
| 隐含波动率偏低 vs 高 short% | `option_quote` | 做市商定价错误（或对冲冗余） |

## 3. 成交轨迹：参与者在哪成交

### Volume Profile · 成交量分布

参与者不会在所有价格都愿意交易。在特定价格区间成交量集中（Value Area），说明买卖双方在此**达成共识**；价格突破价值区域且放量，说明参与者逻辑已变。

| 概念 | 含义 | 用法 |
|---|---|---|
| **POC (Point of Control)** | 成交量最大的单一价格 | 参与者集体认同的价值中枢 |
| **Value Area High (VAH)** | 顶部 70% 成交量的上沿 | 卖方开始压制的价格 |
| **Value Area Low (VAL)** | 底部 70% 成交量的下沿 | 买方开始承接的价格 |
| **VPIN / Delta** | 每分钟 buy vs sell 指令差 | 谁在主导方向 |
| **Block Trade Delta** | 大单成交方向 | 机构意图 |

**实现方式：** 用真实 K-line + volume 数据计算 POC/VAH/VAL；当前 skill 不捆绑独立 `volume_profile.py`。需要该层时从 LongBridge/MCP/用户提供数据读取成交量分布，并在报告中明确数据粒度、时间窗和缺口，禁止声称调用不存在的脚本。

### 成交数据映射到参与者

| 可观察事实 | 最可能的参与者解释 |
|---|---|
| 价格上涨 + 成交量放大 | 新买家入场（非存量博弈） |
| 价格上涨 + 成交量萎缩 | 卖家惜售，存量持有者行为 |
| 价格下跌 + 成交量放大 | 恐慌卖盘或机构减仓 |
| 价格下跌 + 成交量萎缩 | 正常流动性枯竭，供需双萎缩 |
| POC 上移 + 价格在其上方 | 参与者集体提升价值认同 |
| 突破 VAH 放量 | 卖方压制被新买盘突破，参与者范围扩大 |
| 跌穿 VAL 缩量 | 买方不接了，下方无自然买盘 |

## 4. 操作协议：Step 0

**在任何交易判断之前，先执行 Step 0（第一性原理检查）：**

### Step 0a：画参与者图谱

```
参与者组成：
- 产业资本/创始人：_%  信念：[高/中/低]  最近行为：[增/减/无]
- 主动基金：_%         信念：[高/中/低]  最近行为：[增/减/无]
- 被动ETF：_%          变化：[流入/流出/稳定]
- 散户：_%             情绪：[亢奋/观望/恐慌]
- 空头：_%             成本：[高/中/低]  拥挤度：[高/中/低]
- 回购：_%             活跃度：[活跃/暂停]

边际买家：______
边际卖家：______
当前谁更强：______
```

### Step 0b：查动机是否已变

```
最近催化剂：_________
机构是否已反应？[是/否] 证据：_________
散户是否已反应？[是/否] 证据：_________
空头是否已反应？[是/否] 证据：_________
还有未定价的信息？_________
```

### Step 0c：查成交轨迹

```
当前价 vs POC：_________
当前价 vs VAH：_________
当前价 vs VAL：_________
成交量状态：[放量/缩量/正常]
Delta方向：[买多/卖多/平衡]
```

### Step 0d：形成判断

```
参与者流描述：______________________
（例：机构在减持但散户在抄底，短期谁主导？）
主要风险：______________________
（例：机构减持未完，散户买盘耗尽是下行风险）
```

### Step 0 输出给 Decision Compiler

```yaml
module: "participant_flow"
max_action_level: "L0|L1|L2|L3"  # 参与者结构稳定→更高级别可考；结构剧烈变化→降级
position_multiplier: 0.0-1.0   # 主导流与方向一致→乘数可>0.5；逆主导流→≤0.3
hard_veto: false
reason: "Who are the marginal buyers/sellers and what changed their motivation"
confidence: 0.0
```

## 6. 约束

- **参与者流是第一性原理层，必须先于其他方法论执行。** 在戴维斯双击、Serenity、Capex 轮动、Gamma 结构之前，先回答“参与者是谁、他们的动机变了吗”。
- **参与者图谱只能使用可验证数据**（13F、CCASS、short interest、公开单笔交易、cap flow）。不可以凭空猜测“基金在想什么”。
- **边际买家/卖家判定是概率性的**。当数据不足时标注 `participant_gap`，降级决策。
- **Step 0 不单独决定动作等级**。它输出 `participant_flow` module_signal 进入 Decision Compiler，与其他模块共同裁决。
- **参与者流与流动性的关系：** 参与者流变化是原因，流动性恶化是结果。高参与度但方向一致→趋势延续；低参与度→随机波动。
- **逆主导流交易必须有过硬催化剂。** 如果你要逆着当前主导参与者方向做，必须能明确回答“什么能让他们改变主意”。
