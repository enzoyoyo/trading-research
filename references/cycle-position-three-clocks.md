# Cycle Position Three Clocks · 周期三时钟与类比先验门

> 来源边界：蒸馏自 Balder 2026-07-02 Substack《The Memory Trade on Nvidia Time》（公开全文）、Citrini 2026-07-01 DRAM/Jevons 帖与 2026-06-22 Getty/Shutterstock 复盘帖、Frank 2026-06-13 注意力时代帖。文中 MU/NVDA/存储周期数值是 **2026-07 实例，禁止照抄**到其它周期或标的；机制可迁移、实例不可套用。

## 核心命题

一只强周期/强叙事股票同时走**三个不同步的钟**。大多数踏错不是方向错，而是只看了一个钟：

| 钟 | 读什么 | 2026-07 实例（MU，仅示意） |
|---|---|---|
| `fundamentals_clock` 基本面钟 | 增长加速度、beat 幅度与频率、指引 vs 共识、capex 节奏、订单/长约覆盖 | 营收 +346% YoY、beat 超指引 23%+、FQ4 指引大超共识 → 业绩峰在前方 |
| `sentiment_clock` 情绪钟 | 杠杆 ETF 出现、margin debt、散户参与度、预测市场对 beat 的定价、是否指数最佳表现股 | 全套泡沫配件齐备、预测市场 96% beat 概率但对股价能否守住只有掷硬币信心 |
| `valuation_clock` 估值钟 | forward PE 及其相对模板/同类的位置、市场是否已把 peak earnings 定价为「近顶后衰退」 | 8.9× forward——de-rating 已发生，市场把 FY27 定价为近峰 |

三个钟可以严重背离：**基本面钟还在上午，情绪钟已到午后，估值钟已经收盘**。只有三钟合看，才能回答"业绩好为什么不涨/业绩差为什么不跌"。

## 三峰分离（business / multiple / price 三个顶不同时到）

先分别裁决三个峰的状态，再谈动作：

- `business_peak`：业绩顶。看订单/长约覆盖年限、新增供给到达时间、需求破坏证据。
- `multiple_peak`：估值顶。看 forward multiple 是否已嵌入"周期终局"折价——multiple 先于业绩见顶是常态。
- `price_peak`：股价顶。最敏感的合成读数是**财报反应质量**：beat 之后股价的反应（先涨后跌、beat 不再产生 pop）是三钟合成的现场投票。

> 判定示例（机制）：业绩未见顶 + 估值已见顶 + 股价处于中段整固 = 「后半场持有」状态——未来回报只来自 estimate revision，不再来自估值扩张；每次财报都是一次表决而非催化。

## 二阶导数规则（second_derivative）

一阶指标（涨价幅度、增长速度）还在正区间，但**二阶（加速度）翻负**时，情绪钟与估值钟通常先于基本面钟见顶：

- 例（机制）：合同价环比涨幅从 90-95% 回落到指引的 40-50%——价格还在涨，但 `second_derivative=rolled_over`。
- 纪律：`second_derivative=rolled_over` 时禁止把「还在涨」写成「趋势完好」；必须在报告中显式给出一阶/二阶两行读数。

## 七路标 checklist（signpost framework）

周期真顶不会出现在财报标题里，会先出现在可测路标上。逐条登记、可复核，输出 `signpost_count/7`：

1. 合同/现货价格环比走平（涨价引擎熄火）。
2. 新签长约价格低于现货（买方开始赢回定价权）。
3. 竞争对手宣布大额 capex（高毛利引来供给）。
4. 需求破坏出现（价格敏感环节开始削减用量/换方案）。
5. beat 不再产生股价 pop（财报反应质量恶化）。
6. forward estimates 开始下修（共识引擎反转）。
7. 杠杆清算/margin call（情绪钟强制归零）。

纪律：`signpost_count=0` ≠ all-clear（只说明顶不在眼前）；`signpost_count>=2` 时 fundamentals 模块必须收紧，`>=4` 视同周期顶部确认进入 L4 讨论。路标只能收紧、不能加分。

## Jevons / 效率反噬检查（jevons_check）

任何**投入品价格超级周期**论点（存储、电力、GPU 租赁、任何要素涨价逻辑），必须回答 Citrini 问题：

> 价格不可能持续暴涨而不催生「省着用」的创新。做多涨价受益方 = 做空「被逼出来的创新」。

- 必答三问：① 涨价触发的效率创新路径是什么（软件优化/替代方案/架构变化）？② 响应时间多长（`thesis_half_life`）？③ 谁是效率响应的受益方（对冲腿候选）？
- 答不出 `thesis_half_life` 的涨价论点，最高只能按「已进行中的周期」交易，不得按「新常态」估值。

## 论点-交易转化门（thesis_trade_gate）

Citrini Getty 教训：**论点最终正确，交易仍然失败**。论点有效性与交易可行性必须分开裁决：

| 维度 | 问题 | 缺失时 |
|---|---|---|
| `thesis_validity` | 逻辑与证据是否成立 | 不进 watchlist |
| `path` | 从现在到兑现，价格路径中间会发生什么（谁先被杀） | 只能小仓/期权化表达 |
| `timing_catalyst` | 有没有可写出日期的催化时间表 | 默认 watchlist，不入场 |
| `carry_cost` | 等待期间的持有成本（theta/资金/机会成本） | 成本盖过预期收益→放弃表达 |

「eventually right」没有 timing_catalyst 时 = 研究结论，不是交易。

## 类比先验纪律（analog_prior）

「X 是 Y 的 2024 年 6 月」这类模板映射（Nvidia template 等）一律记 `analog_prior`，纪律对齐 `modeled_scenario`：

- 只作 scenario_prior / watch_priority / evidence_collection_plan，`position_multiplier=0.0`，不进仓位计算。
- 由类比推出的价格区间（如 analog 回撤带）只能记 hypothesis，禁止写成目标价。
- 合格类比必须**双侧列断裂点**：`analogy_breaks_bearish`（本轮比模板更差的结构差异）与 `analogy_breaks_bullish`（更好的结构差异），缺任一侧 = 不合格类比、不得引用。
  - 2026-07 实例（仅示意）：bearish——存储无 NVDA 定价权、85% 毛利引来竞对 capex 与监管；bullish——三寡头 vs 历史八家、HBM 多年长约非现货、hyperscaler 需求。
- 注意力时代修正（Frank）：中短期定价里叙事/注意力权重上升是参与者结构事实——时间框架分离时，**短线**读 sentiment_clock 权重更高；但这只改变时间框架的权重分配，不改变 falsifier 纪律、不否定中线基本面裁决。

## 输出格式

```yaml
cycle_position_three_clocks:
  target: "<symbol>"
  fundamentals_clock: "early|mid|late|peaking|past_peak"
  sentiment_clock: "early|mid|froth|unwinding"
  valuation_clock: "expanding|peaked|derated"
  business_peak: "ahead|near|behind"
  multiple_peak: "ahead|near|behind"
  price_peak: "ahead|mid_consolidation|behind"
  earnings_reaction_quality: "pop|fade_after_pop|no_pop"
  second_derivative: "accelerating|flat|rolled_over"
  signpost_count: 0  # /7，逐条列出已触发项
  jevons_check:
    efficiency_response: "<路径>"
    thesis_half_life: "<时间估计|unknown>"
    hedge_beneficiary: "<候选|none>"
  thesis_trade_gate: "pass|watchlist_only|no_trade"
  analog_prior:
    template: "<X is Y's <date>|none>"
    analogy_breaks_bearish: ["..."]
    analogy_breaks_bullish: ["..."]
    status: "scenario_prior_only; position_multiplier=0.0"
```

## 与 Decision Compiler 的关系

- 三钟/三峰/二阶/路标结论编译进 `fundamentals`（业绩与估值裁决）与 `endogenous_structure`（情绪钟/杠杆配件）；不新增 module、不新增动作等级。
- `signpost_count>=2`、`second_derivative=rolled_over`、`earnings_reaction_quality=fade_after_pop|no_pop` 都只能**收紧**动作上限或触发 L4 讨论，不能反向加分。
- `analog_prior` 按 `modeled_scenario` 同档纪律：最高提高 watch priority / scenario prior，`position_multiplier=0.0`。
- 与 `prosperity-davis-double-framework.md` 的关系：戴维斯双击管「进场资格」（双门槛），本文件管「周期钟点与退出路标」；两者都编译进 fundamentals，冲突时取更保守档。
- 与 `capex-cashflow-duration-rotation.md`、`second-order-supply-shock-mapping.md` 交叉引用：涨价受益方（receiver）同时要过 jevons_check 与七路标。

## 常见误判

1. **只看基本面钟**：业绩加速就长持，无视情绪钟泡沫配件与估值钟已定价 peak。
2. **把 de-rating 当便宜**：低 forward PE 可能是市场对「近峰后衰退」的正确定价，不是安全边际。
3. **把类比当证据**：模板映射是提问工具，不是回报预测。
4. **一阶思维**：只看「还在涨」，不看涨幅的加速度。
5. **论点正确=交易正确**：无时间表的正确论点照样亏钱。

## 失效条件

- 标的无清晰周期属性（稳态现金流/防御类）→ 本框架降权，回到 expected-returns / DCF 边界。
- `risk_regime=active_deleveraging|forced_liquidation` → 三钟读数全部让位系统风险。
- 三钟读数所需数据（beat 历史/共识/杠杆配件证据）缺失 → 标注 `clock_gap`，只输出可读的钟，不硬补。
