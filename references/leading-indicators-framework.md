# Leading Indicators Framework · 先行指标监测框架

> 将产业链上游可观测数据点转化为对下游量产进度的预判信号。适用于任何处于"商业化导入期"的技术主题——当财务数据尚不能反映叙事时，先行指标是最重要的基本面证据。

## 核心原则

1. **先行指标是极早期赛道的"基本面"**——在营收兑现前，先行指标是唯一可验证的硬数据
2. **领先期越长，信号价值越高，但确定性越低**
3. **先行指标必须可观测、可追踪、有明确的数据源**
4. **信号方向（利好/利空/待观测）比具体数值更重要**

## 先行指标分层

| 层级 | 领先期 | 典型指标 | 数据源 |
|---|---|---|---|
| 材料端 | 1-6 月 | 上游原材料价格/出货量、特种材料部门营收 | 公司季报、行业报告 |
| 设备端 | 1-4 季 | 设备订单/backlog、CAPEX 指引、WFE 支出 | 公司季报/电话会、SEMI |
| 产能端 | 3-4 季 | 工厂建设进度、良率爬坡、资本开支 | 公司公告、行业新闻 |
| 需求端 | 同步 | 下游客户导入、营收占比变化 | 下游公司季报/法说会 |
| 技术端 | 12-24 月 | 专利申请增速、技术路线图更新 | WIPO、学术会议 |

## 先行指标仪表盘

对每个主题构建：

| 序号 | 指标 | 数据源 | 领先期 | 当前读数 | 信号方向 | 置信度 |
|---|---|---|---|---|---|---|
| 1 | 核心材料供应商相关业务部门营收 | 季报 | 1-2 季 | $X, YoY +Y% | ↑ 利好 | 中高 |
| 2 | 核心设备商订单/backlog | 季报/电话会 | 2-3 季 | 待 Q3 财报 | → 待观测 | 中 |
| ... | ... | ... | ... | ... | ... | ... |

### 信号方向判断
- ↑ 利好：当前读数支持产业化加速假设
- ↓ 利空：当前读数不支持或反驳产业化假设
- → 待观测：数据尚未发布或不足以判断

### 置信度标注
- 高：一次信源（公司季报/公告），数据可直接验证
- 中高：一次信源，但指标与主题的因果关系存在一步推断
- 中：二次信源（行业报告），含推断成分
- 低：早期信号，因果关系不明确

## 先行指标的筛选标准

一个好的先行指标必须同时满足：
1. **可观测**：有公开、定期更新的数据源
2. **有领先性**：领先目标事件至少 1 个季度
3. **有因果链**：能从逻辑上解释为什么这个指标领先于目标事件
4. **低噪声**：不会因为短期波动而频繁改变信号方向

反例（不应纳入的指标）：
- LPKF 股价变化（被先行指标领先，不是领先指标本身）
- 社交媒体讨论热度（噪声太大）
- 无法定期更新的单次事件

## 核心先行指标深度分析模板

对每个一阶先行指标，写清楚：

```
### 指标 X：[名称]

**为什么这个指标有领先性**
- 因果链：A → B → C → 目标事件
- 每步的时滞估计

**当前状态**
- 最新读数
- 与历史趋势的对比
- 信号方向：↑/↓/→

**关键阈值**
- 什么水平的读数算"强烈利好"
- 什么水平的读数算"预警信号"

**下一次更新**
- 预期日期
- 在此之前，信号方向的可靠性
```

## 综合判断规则

当多个先行指标同时发出信号时：
- ≥50% 指标利好 + 0 利空 → 产业景气度正在积聚
- 利好+待观测 > 利空 → 维持乐观假设，等待待观测指标明朗
- 出现 ≥1 个利空信号 → 降级乐观程度，重新检视假设
- 待观测比例 >60% → 先行指标系统不够成熟，降低对先行指标的依赖

## 先行指标失效的三种情况

1. **技术路线证伪**：如果先行指标监测的技术路线被官方放弃或替代方案被确认为主流
2. **领先期缩短**：当产业链进入量产阶段后，先行指标的领先价值降低——应逐步切换至财务数据
3. **数据源中断**：关键公司停止披露相关数据——标注缺口，降低依赖

## 与 EID 证据账本的对接

每条先行指标的当前读数应作为一条 EID 进入证据账本：
- 证据类型：产业链/先行指标
- 方向/强度：按信号方向映射 Bull/Bear/Neutral，强度按置信度映射 -2~+2
- 可靠性：高=0.8、中高=0.7、中=0.5、低=0.3
- 决策影响：利好信号提高仓位上限（在 regime 限制内），利空信号触发降级

## 与决策级联的对接

先行指标在决策级联中的作用：
- L0→L1 升级：至少 2 个先行指标发出利好信号
- L1→L2 升级：先行指标利好 + 财报/公告验证（在早期赛道中，设备订单落地 = 替代传统财报验证）
- L2→L3 降级：任一核心先行指标转为利空
- L4 触发：多个先行指标同时转为利空，或核心先行指标被证伪
