# Liquidity-Valuation Duality · 流动性-估值二象性

> 参考刘备（星球干货 NO.2-77 至 NO.2-79「两种估值方法」系列）。核心命题：估值方法的切换本质是对流动性环境的适应——**不考虑流动性的静态估值是耍流氓**。

## 两种估值体系

| | 古典价值 | DCF 现代价投 |
|---|---|---|
| **前提** | 低流动性环境 | 高流动性环境 |
| **核心假设** | 价值（主人）位置恒定 | 价值区间由共识叠加构成 |
| **可精确度** | 可精确测度（清算价值/现金流） | 只能估算模糊区间 |
| **类比** | 牛顿力学 | 量子力学——位置和速度基于概率 |
| **有效场景** | 熊市、低流动性板块、冷门股 | 牛市、高流动性板块、赛道股 |
| **代表** | 格雷厄姆、早期巴菲特 | 后巴菲特、彼得·林奇 |

## DCF 的本质

> DCF = 同时考虑**现金流**和**市场流动性**的估值模型。

折现率（无风险利率水平）本身就是一个体现流动性的指标：
- 折现率低 = 流动性好 → 未来现金流值钱 → 高估值
- 折现率高 = 流动性差 → 未来现金流打折 → 低估值

所以 DCF 已经**模糊了价值定价和流动性定价的边界**。不是因为方法错了，而是因为现实中价值和流动性从来不可分。

## 现金流久期切片

同一成长主题里，不能只问“是不是成长股”，还要问现金流离现在有多远：

| 现金流久期 | 典型形态 | 折现率上行时 | 折现率下行时 |
|---|---|---|---|
| **短久期 / 当前现金流** | 已经卖货、订单/收入/毛利可见，Capex 收钱方 | 相对抗折现；但仍受周期和估值拥挤影响 | 受益但弹性未必最高 |
| **长久期 / 未来现金流** | 现在投入大 Capex，未来靠平台化/渗透率/利润率兑现 | 估值折扣更大；需验证未来回报率 | 久期重新值钱，估值弹性更大 |
| **混合久期** | 当前收入可见，但关键 alpha 来自未来份额/渗透率 | 逐票拆，不可一概而论 | 逐票拆，不可一概而论 |

AI/半导体内部用 `capex-cashflow-duration-rotation.md` 细拆：hyperscalers 可能是 `capex_payer_future_monetizer`，供应链可能是 `capex_receiver_current_cashflow`。这是估值解释和相对配权 overlay，不是单独买卖信号。

## 四层流动性

| 层级 | 驱动因素 | 持续时间 | 对估值的影响 |
|---|---|---|---|
| **1. 全球放水** | 各国央行超发货币 | 长周期（10年+） | 所有资产长期看涨，不持有现金 |
| **2. 股市自身** | 牛熊切换 | 中周期（1-3年） | 牛市高流动性→DCF主导；熊市低流动→古典价值回归 |
| **3. 赛道流动性** | 机构长期看好某些行业 | 中长周期（数月至数年） | 只要大逻辑不被证伪，流动性保持→高估值中枢 |
| **4. 游资炒作** | 人为制造 | 短周期（天-周） | 来得快去得快，不确定性极高，不依赖 |

前三层流动性叠加越多，估值越高。第四层不参与估值判断。

## N 层流动性叠加判断

对任一标的，先判断它处于几层流动性的叠加：

```
叠加层数 = 全球放水(✓/✗) + 股市牛熊(✓/✗) + 赛道热度(✓/✗)
```

- **3层叠加**：DCF 极端乐观端 → 高估值但高拥挤风险
- **2层叠加**：正常 DCF 区间 → 主流估值方法有效
- **1层叠加**：古典价值区间 → 可以算清算/现金流底
- **0层叠加**：深度价值 → 只看资产，不看故事

## 牛/熊/分化年（A股历史规律，2005-2019）

| 年份类型 | 年份 | 特征 |
|---|---|---|
| **牛市年** | 06, 07, 09, 14, 15, 19 | DCF 主导，全面高估值 |
| **熊市年** | 05, 08, 11, 16, 18 | 古典价值回归，跌到清算/股息底 |
| **分化年** | 10(500强), 12(300强), 13(500强), 17(300强) | 结构性牛市，部分板块 DCF，其余古典价值 |

分化年（结构性牛市）是最需要这一框架的场景：同一市场中，赛道股用 DCF 估值（40-100倍 PE），冷门股只配用古典价值（5-10倍 PE）。
