# Poisson Method · 事件强度 λ / 证据临界密度 / 高质量等待 / 单位时间 EV

> 来源：《投资是泊松过程》(BayesCrest)。这是本 skill 的**底层择时与仓位纪律**，不是普通技术指标。
> 它不回答「明天涨不涨」，而回答「现在该不该下注、下多少、在等什么、什么时候认错」。

## 0. 一句话内核

收益不是连续函数，而是**稀疏事件驱动的状态跳变过程**：大部分时间什么都不发生，命运由少数关键事件决定。
所以买的不是股票代码，**买的是向上状态跳变的强度 λ**；等的不是时间，**等的是证据网络达到临界密度的那一刻**。

数学骨架：事件次数 `N(t) ~ Poisson(λt)`；两次事件的等待时间 `T ~ Exponential(λ)`，均值 `E[T]=1/λ`。
λ 越高，下一个催化越近；λ 越低，等待越长。

## 1. λ —— 向上状态跳变的强度（核心变量）

λ 不是「跌多了该涨」，而是「未来一段时间内出现真实利好状态迁移的概率密度」。按资产类型，λ 的含义不同：

| 资产类型 | λ 的具体含义（在等什么事件） |
|---|---|
| 财报型公司 | 下季度 beat / raise / KPI 加速的强度 |
| AI receiver（算力/供应链下游） | 被订单、客户、capex、毛利验证的强度 |
| 周期股 | 价格、库存、产能利用率反转的强度 |
| 软件股 | RPO / NRR / AI attach rate / sales productivity 改善的强度 |
| 事件驱动 | 并购、监管、重组、指数纳入、回购等催化到来的强度 |

### λ 的四种状态 → 仓位含义

| λ 状态 | 投资含义 | 默认动作 |
|---|---|---|
| λ 低 | 催化稀疏、长期等待 | 小仓位或纯观察 |
| λ 上升 | 状态迁移概率提高 | 值得加大研究与建仓准备 |
| λ 高 | 催化密集，可能进入重定价窗口 | 仓位上限可上调（仍受座位与风控约束） |
| λ 下降 | thesis 进入低反馈期 | 重新评估机会成本，准备降权/退出 |

**判断 λ 方向只看证据斜率，不看价格跌幅、不看时间长度。**

## 2. 证据网络与临界密度

λ 上升还不够，要看**证据有没有结成网络**。

- 一条新闻、一句管理层口号 **不是**证据网络。
- 证据网络 = 多个**独立**信号互相印证：客户在买、收入在加速、毛利没崩、订单在增长、行业趋势配合、而股价还没完全反映。
- 当独立证据彼此确认、密度接近临界，而市场尚未定价 —— **这是赔率最高的时刻**（λ 已明显上升、证据快成型、价格仍滞后）。

判断证据密度的三问：
1. **λ 在不在升**：好事发生强度变高，而不是「跌多了」。
2. **证据在不在变密**：数据/客户/财务/产业链/价格行为互相确认，而不是同一故事被反复转述。
3. **市场定价是否仍滞后**：还有没有 pricing slack（错误定价空间）。

## 3. 高质量等待 vs 低质量等待（职业纪律）

「大部分时间在等待」不是消极，是纪律。但要严格区分两种等待：

**低质量等待 = 叙事麻醉（资本钝化，必须避免）**
- 没有证据更新；
- 没有明确 falsifier（证伪条件）；
- 没有 review clock（复盘时钟）；
- 只是因成本价 / 情绪 / 旧 thesis 不愿动；
- 价格跌了就说「长期主义」。

**高质量等待 = 投资版泊松过程（值钱的能力）**
- 知道自己在等哪个具体事件；
- 知道事件没发生前不该乱动；
- 知道事件发生后如何更新后验；
- 知道什么证据出现就退出；
- 知道仓位大小要与等待期风险匹配；
- 知道不是所有等待都值得继续。

## 4. 无记忆性陷阱（最反人性的一点）

指数分布的等待时间具有**无记忆性**：已经等了很久，**并不意味着下一个机会更近**。
以下都不是证据，只是「等待时间幻觉」，**禁止作为加仓/抄底理由**：
- 「这票跌这么久了，该反弹了。」
- 「这行业沉寂这么久了，该轮到了。」
- 「这公司讲了这么多年 AI，该兑现了。」
- 「估值压这么久了，市场该修复了。」

正确的提问永远是：λ 升了吗？证据斜率转正了吗？状态迁移进入可验证阶段了吗？定价还滞后吗？没有这些，时间本身没有任何投资价值。

## 5. 单位时间 EV 公式（仓位与取舍的量纲）

```
Investable EV per unit time
≈ λ × P(valid state jump | event) × Payoff
  − Carry Cost          (等待期资金/波动/时间成本)
  − Fragility Cost      (等待期基本面被击穿的风险)
  − Opportunity Cost    (别的座位是否更好)
  − False Positive Cost (把噪音误当状态跳变的代价)
```

- `λ`：事件到来强度。
- `P(valid state jump | event)`：事件真发生后，是真迁移还是噪音。
- `Payoff`：状态跳变带来的非线性赔率（上行赔率 / 下行损失）。

**用法**：当某标的 `λ×P×Payoff` 高、且四类成本可控时，提高泊松择时权重与仓位准备；任一成本失控（尤其 Fragility 与 False Positive），即便 λ 高也降权。

## 6. 四象限：把资产按 λ × Payoff 归位

| | 高 Payoff | 低 Payoff |
|---|---|---|
| **高 λ** | 核心狩猎区：催化密集 + 非线性赔率，市场常误判为普通周期 | 频繁但收益薄：交易成本易吃掉 EV |
| **低 λ** | 最常见错配：把它当核心重仓 = 长期套牢源头，只配小仓位/凸性敞口 | 资本钝化区：不碰 |

两类典型错误：
- 把 **低 λ + 高 payoff** 错配成核心仓位（彩票当主仓）。
- 把 **高 λ + 高 payoff** 误判成普通周期而错过（机会就在别人看不懂时）。

## 7. 现金、杠铃与座位拍卖

- **现金不是空仓，是等待事件的选择权**。机会随机到来，现金保留了「在高 λ、高 payoff、高 pricing slack 事件出现时快速换座」的权利。
- **过去的仓位没有神圣性**：每个时点都要重新拍卖座位 —— 现有持仓若 EV 低于现金+新机会，就该让位。
- **杠铃契合**（呼应 IMA《历史会押韵吗》杠铃策略）：大部分低风险底仓 + 小部分高凸性稀疏事件敞口，正是泊松世界的最优形状 —— 用有限下行换右尾非线性。

## 8. Poisson Waiting Discipline（落地纪律）

> 投资不是持续行动系统，而是稀疏状态跳变捕捉系统。大部分时间应用于**维护证据网络、反证条件、仓位合法性、心理耐受**，而不是制造交易。

最危险的行为是**无事件期过度行动**：
- 天天找理由加仓；用小新闻替代大证据；因无聊换股；因波动否定 thesis；因市场短期不承认而提前离开；因等急了把低质量信号当催化。
- 泊松过程的铁律：**没有事件就是没有事件，等待本身是模型的一部分。**

## 9. 在本 skill 中的应用规则

1. **事件强但位置差**：不追，等回踩/确认（座位非法时 λ 再高也只观察）。
2. **位置好但事件弱（低 λ）**：只观察或轻仓试错，不重仓。
3. **λ 上升 + 证据变密 + 座位合法**：提高泊松择时权重，仓位准备前置（在证据完全显性化前用合理仓位买入「强度上升的过程」）。
4. **事件后事实不兑现**：快速降权，不把旧事件当新理由。
5. **区分四种状态**：价格噪音（可等）/ 证据恶化（不能用泊松等待自我安慰，要退）/ 状态迁移失败（退）/ 机会成本上升（换座）。
6. **无记忆性红线**：任何「跌够久/沉默够久该涨了」的论证，一律视为噪音，不得提高仓位。

## 10. 输出字段（每次涉及择时/仓位/持仓处理时必填）

```markdown
泊松择时：
- λ 方向：上升 / 高位 / 下降 / 低位（依据：__证据斜率，非价格/时间__）
- 在等什么事件：财报 / 订单 / 政策 / 产业价格 / 指数纳入 / 并购 …（具体到可验证节点与日期）
- 证据网络密度：稀疏 / 接近临界 / 已临界 / 正在恶化（列出互相印证的独立信号）
- 座位合法性：价格位置 / 流动性 / 止损空间 / 账户仓位 是否允许下注
- 单位时间 EV 判断：λ×P×Payoff vs Carry/Fragility/Opportunity/FalsePositive
- falsifier（证伪/退出条件）：出现什么证据就认错
- review clock（复盘时钟）：下一个数据/事件节点是什么时候
```
