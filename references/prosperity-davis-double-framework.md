# Prosperity Davis Double Framework · 景气度·戴维斯双击框架

> 主落点声明：编译进 `fundamentals`；不新增动作模块。

> 参考《景气度投资分析框架 v1.0》（中观景气度投资研究员方法论：投资景气行业龙头，追求戴维斯双击）+ 公募选股方法论的「极致集中输出审美」。
> 核心命题：一切分析收敛到一个问题——**未来 2-3 年，这个行业/公司的业绩会不会持续超预期？**
> 这不是价值投资框架：不做 DCF、不算内在价值、不谈安全边际、不谈长坡厚雪。商业模式只决定下限，不决定一两年维度的涨跌。

## 适用范围与不可迁移锚点（先读）

**方法论 A/H/美股通用**（与 Serenity/刘备/洪总同档：机制可迁移）。戴维斯双击本身是跨市场概念，文档案例也跨市场（纳指 1999、美伊冲突 2026、旭创/新易盛 2025 关税）。但下列 **A 股专属数值锚禁止直接套用到港股/美股**，必须按当地事实重填——纪律等同 `deleveraging-liquidity-squeeze-playbook.md` 顶部「机制可迁移、实例不可套用」。

| A 股专属锚点 | 数值/形态 | 港股/美股怎么办 |
|---|---|---|
| 科技股估值区间 | 10-40 倍（A 股科技股本质是制造业：乐观=先进制造、悲观=铁皮桌子加女工） | 按当地行业估值分布重算，不套 10-40 |
| 消费型单一中观指标 | 白酒 = 批价 | 找当地品类的等价中观指标，不照搬批价 |
| 估值卖出纪律 | 制造业第二年预测利润 40 倍触发卖出警报 | 按当地行业估值中枢与历史顶部区间重标 |
| 公募极致集中审美 | 2-4 核心 + 2-4 观察、≤8 只 | 集中度纪律可迁移；但「公募会怎么配/什么位置进」属 A 股资金风格，不强加到美股 |

## 不冲突契约（硬约束）

1. **「不做 DCF」只在本方法内部生效**：景气度投资刻意把估值降为「比较工具」、放到最后一步，**不否定** `liquidity-valuation-duality.md`。两者都是 `method-rotation-matrix.md` 里的方法，由 regime 决定本次主导哪套：高流动性/赛道牛市仍可用 DCF；本框架适用于景气周期可识别且足够长时。
2. **「宏观降权」不触碰 risk_regime**：本框架的宏观降权只针对**选股方向判断**（不做宏观择时——不靠预测利率/GDP 方向决定买什么；强产业周期里分子跑得比分母快）。宏观只进入第 8 步「回撤归因」。但这**绝不覆盖** `risk_regime` 的系统性风险保护层——`active_deleveraging`/`forced_liquidation`/Gamma hard veto 仍是最高优先级，按 Decision Compiler 裁决。**系统性去杠杆保护 ≠ 宏观择时**，两者是不同的东西。
3. **不新增动作等级、不真实下单**：本框架结论编译进 `fundamentals` 模块，最终动作由 Decision Compiler 裁决；不给具体仓位比例/杠杆（与 `no_order_execution` 一致）。

## 0. 强约束（基本原则）

- **信息有效性过滤器**：只有对未来两年盈利预测有影响的信息才是有效信息，其余只影响情绪。引用任何信息前先过这道滤网；不靠信息多取胜，靠理解信息取胜。
- **想长做短**：判断建立在 2-3 年产业趋势上，操作可以是 1 年维度；不做短期股价高低位切换（那是筹码博弈，归 `a-share-short-term-layer.md`）。
- **中观先于个股**：先回答「行业景气吗、还能景气多久」，再回答「买谁」。
- **估值是比较工具不是计算工具**：估值永远最后考虑（见第 3 步顺序）。
- **数据时效**：订单/交期/价格/库存/一致预期必须用最新可得数据并标注时点；无法获取标注「未知/待核验」，进入 Mira Quality Gate。

## 1. 行业景气诊断（胜负手）+ 周期长度判断

景气诊断的「订单饱满/交期拉长/挑单/涨价/毛利方向/供需缺口/产业周期位置（早期超额利润集中在上游瓶颈‘缺 X 逻辑’，上游变便宜后利润向中下游/端侧扩散）」**直接复用 `serenity-method.md`**。本框架在其上加一个**决定性 gate**：

**周期长度判断 = 整个框架的胜负手**
| 周期长度 | 处理 |
|---|---|
| ≥2 年 | 才值得进入重仓讨论 |
| 1-2 年 | 可参与，但仓位与 conviction 下调 |
| <1 年 / 判断不出长度 | 全篇结论自动降级，并在结论里显式声明「周期长度不可判 → 降级」 |

硬规则：越长的周期越不容易犯错，胜率赔率同时提高。判不出长度 = 自动降级，不靠拍脑袋补。

## 2. 戴维斯双击双段收益（必须分别识别）

机制链：业绩超预期 → EPS 上行（**第一段**收益）→ 若超预期是**板块性**的，市场对行业增长线性外推 → 估值容忍度上调（**第二段**收益）。
- 个股性 beat 只赚 EPS 的钱（只有第一段）。
- 只有**板块性**业绩超预期才触发市场线性外推 → 估值抬升（第二段）。
- 报告必须分别标注：这次是只有第一段，还是双段都有。

## 3. 类型归类（三选一，决定打法）

| 类型 | 核心规则 | 关键指标 | A 股锚（不可迁移） |
|---|---|---|---|
| **成长型**（科技/制造） | 行业景气预期方向 > 公司 alpha；景气预期向下时再强 alpha 也无超额（立讯 2018 增速最强但跌 30%+，2019 增速更低却涨 2 倍） | 景气信号链：交期拉长→挑单→涨价→收入高增→固定费用摊薄→利润增速 > 收入增速，逐项核对 | 估值锚 10-40 倍 |
| **消费型** | 找决定股价的单一中观指标，再向上溯源驱动它的下游行业景气 | 三级库存（厂商/社会/终端）钝化波动 → 报表见度高 → 右侧上车仍有收益；消费习惯难改 → 周期天然长，胜率赔率双高 | 白酒 = 批价（← 基建/地产/贸易景气） |
| **周期型** | 见下方两分类 | | |

周期型再分两类：
- **纯周期**（钢铁/煤炭/有色）：看产品价格炒股票，价格是景气度的唯一核心指标，需求端无增长，超额收益全部来自供需变化。
- **周期成长**（历史超额收益最大来源，重点识别）：主业被某个外部变量驱动（如油价位置 → 油公司 CapEx 意愿）+ 存在第二/第三增长曲线、有再造公司潜力。
  - 底部信号：行业里只有龙头赚钱、其他人都亏损，周期选手开始介入。
  - 接力结构：周期选手先买（赚周期向上的主业钱）→ 成长选手接力（赚周期股估值 → 成长股估值切换的钱）。识别当前在哪一棒。
  - **风险红线**：周期股历史高点都出现在试图切换成长股估值的时刻。必须单独评估成长叙事坚实度——长协是否真锁定？现金流可预测性是真结构变化还是高位叙事？
  - 子规则：贸易/模组类赚价格上行斜率最陡阶段的钱（存货收益，货卖完超额收益就结束）；原厂/资源类赚高价持续时间的钱。买卖点完全不同，不可混用。

## 4. 选股四维度（顺序即权重，不可改）+ 双门槛

顺序：**空间（决定赔率）→ 壁垒（决定买 A 不买 B）→ 确定性（决定胜率）→ 估值（最后考虑）**。
- **空间**：行业未来 3 年空间能否翻倍？公司 2-3 年业绩能否翻倍？小个位数增长的行业长不出大牛股。
- **壁垒**：空间确认后买壁垒最高的环节/公司（自制核心材料 / 良率 / 客户结构 / 卡位）。
- **确定性**：现在就要有业绩，当期报表可验证；**不接受**「1-2 年后才有业绩」、不接受市值空间法。确定性维度直接引用 `expected-returns-framework.md` 的算/问/蒙。
- **估值**：前三项类似 → 买便宜的；前三项有明显差异 → 估值不进决策（便宜往往正因为前三项不如别人）。

**双门槛硬规则**：重仓候选必须**同时**满足「长期空间大」+「短期业绩好」，缺一即出局。
- 空间大但无短期业绩（人形机器人 / 可控核聚变 / 卫星互联网类）→ 归「主题投资」→ 判定【交易性仓位】，不进重仓池；交给 `early-stage-theme-quality-framework.md` 处理（VC 式公开市场机会，须接受低 Quality 评分、无锚、图不好就走，安全边际只来自比别人买得早/便宜）。
- 短期业绩好但空间小 → 赔率不足，不出大级别收益。

## 5. 业绩超预期路径推演

- 未来 2-4 个报表季，超预期来源逐项拆：量 / 价 / 毛利 / 费用摊薄。
- 当前卖方一致预期是什么？你的预测与之差距多大？（用 LongBridge `consensus` / `forecast_eps`）
- 板块性还是个股性？（决定能否触发第二段，见第 2 步）
- 下一个验证 / 证伪时点：财报日、月度数据、产业链排产数据 → 写进 Mira `must_refresh_if`。

## 6. 买点与左右侧（中线，非短线）

- **行情级别 > 左右侧**。判断为 2-3 年级别行情 → 右侧果断上车、回调加仓；涨 40% 之后买入照样可赚很多倍（2023 年 4 月光模块案例）。
- 右侧损失一点赔率，换巨高胜率。
- 操作姿态：长期顺大势，短期逆小势（行情内波动用来加仓，不用来止损）。
- 注意：这是**中线趋势买点**，与 `a-share-short-term-layer.md` 的日内/打板右侧买点是不同时间框架，不混用。

## 7. 卖出与风控三件套（每个标的必须输出）

| 信号 | 触发 | 动作 |
|---|---|---|
| **左侧信号** | 最紧缺的环节/物料变得不紧缺——二线公司也能满产满销（与 Serenity 瓶颈缓解信号同源） | 绝对要走 |
| **右侧信号** | 龙头公司盈利能力出现**不可解释**的单季度下滑（可解释的一次性物料/汇兑不触发） | 减 / 出 |
| **估值纪律** | 制造业达到「第二年预测利润 40 倍以上估值」触发卖出警报（A 股锚，港股/美股按当地重标） | 警报；不保证正确，但避免极端泡沫下犯错 |

## 8. 回撤归因三分法（持有期预案，每个标的预先列出 1-2 个情景）

| 类别 | 含义 | 处理 |
|---|---|---|
| **一类：宏观扰动**（政策/利率/战争/关税） | 不致命，宏观不可预期、传导幅度算不清 | 该忍就忍，不作为卖出理由 |
| **二类：行业增长变差** | 能提前分析出来的 | 该减就减，尊重基本面；基本面起来再买回，错过一段涨幅没问题 |
| **三类：公司 alpha 转负** | 同二类 | 该减就减 |

## 9. 方法适用性自检（输出前必答）

| 当前市场风险偏好 | 本方法表现 | 结论处理 |
|---|---|---|
| 极低（只信分红、红利大行其道，类 2021-2022） | 无超额但大概率仍有绝对收益 | 降级为绝对收益视角 |
| 极高（炒空间不炒当期业绩，类 2015） | 主题股跑赢，本方法跑输但不亏钱 | 显式提示主题风格占优 |
| 正常 | 适用 | 正常输出 |

说明：极端情绪是少数时间，多数时间市场讲道理、看企业盈利。

## 公募极致集中输出审美（选股场景的输出纪律）

公募超额来源 = 在分歧中先于市场定价 + 快速纠错 + 极致集中。多标的选股场景输出时：
- **极致集中**：核心推荐 2-4 只 + 重点观察 2-4 只，总计 ≤8 只。不给 10-20 只散弹清单。
- **敢于排序**：不把所有标的标「推荐」，要有明确优先级；末尾回答「如果只选 1 只选谁、为什么」。
- **远期价值定价透支判断**（必答）：明确回答「当前 PE 对应未来 1-2 年业绩是否透支」。未透支 + 景气级别大 → 核心；已透支 → 只观察不推荐当下买入；分歧大 → 重点分析分歧点。
- **纠错信号**：必须包含「什么情况下应离场」（即第 7 步三件套）。
- **新题材优先**：偏好市场尚未充分认知的方向；若赛道已被广泛覆盖，标注「定价已较充分」。

## 输出结构（固定顺序）

1. 一句话结论：景气状态 + 周期长度判断 + 类型归类 + 双门槛判定
2. 景气诊断证据链（订单/交期/价格/缺口/产业周期位置，标数据时点）
3. 类型归类与对应打法
4. 四维度逐项评估（空间→壁垒→确定性→估值）
5. 双门槛判定：【重仓候选】/【交易性仓位】/【不参与】
6. 业绩超预期路径 + 下一个验证时点
7. 卖出与风控三件套
8. 回撤归因三分法预案
9. 方法适用性声明
10. （集中选股场景）核心推荐 2-4 + 重点观察 2-4，含远期定价透支判断与排序

## 禁止事项

- 禁止用「商业模式好/管理层优秀/品牌强/长坡厚雪」作买入理由——只决定下限，不决定一两年维度涨跌。
- 禁止基于宏观判断（利率/汇率/GDP）给方向性结论。
- 禁止让「空间大但短期无业绩」的标的进入重仓候选。
- 禁止给具体仓位比例/杠杆建议（与 `no_order_execution` 一致；最终仓位上限由 Decision Compiler 给）。
- 禁止用只影响短期情绪、对两年盈利预测无影响的信息支撑任何结论。
- 禁止把 A 股数值锚（10-40 倍 / 批价 / 40 倍）直接套到港股/美股。

## Decision Compiler 映射

本框架**不是新动作模块**，结论编译进 `fundamentals`（景气趋势 / 业绩超预期）：

| 输入状态 | module_signal | 默认动作上限 |
|---|---|---|
| 周期长度 <1 年或判不出 | `fundamentals` | 全篇降级；最高 L1 watch |
| 双门槛只满足一项 | `fundamentals` | 空间大无业绩 → 交易性仓位（最高 L1）；业绩好无空间 → 赔率不足，不重仓 |
| 估值已透支未来 1-2 年业绩 | `fundamentals` | 只观察，不推荐当下买入 |
| 风险偏好极低 / 极高（第 9 步自检） | `fundamentals` | 极低 → 降绝对收益视角；极高 → 提示主题风格占优 |
| 双门槛齐 + 周期 ≥2 年 + 板块性 beat + 未透支 | `fundamentals` | 进核心推荐；但不超过 risk_regime/Gamma/account 允许等级 |

risk_regime、Gamma hard veto、账户合法性、数据缺口仍是更高优先级；景气度结论永远在 Redline Cap 之下——能改变「先看谁、配多少 conviction」，不能改变「系统性风险下能不能买」。
