# Counter-Consensus Framework · 逆共识交易框架

> 参考洪总「HH 深圳春季分享会」（2025.3）及三个月前分享会核心内容。核心命题：**大周期方向 > 小波动。在模式转变期，传统框架失效，逆共识才是超额收益来源。**

## 核心原则

### 1. 大周期嵌套
大小周期相互嵌套形成「嵌套式」大趋势。一旦判断错误大周期方向，损失难以弥补。小波段/单周波动对长期收益影响不大。

```
大周期方向判断 → 资产配置（股/债/金/现金） → 市场选择（A/H/美） → 板块轮动 → 个股选择
```

### 2. 边际定价
市场共识已充分反映在价格中。价格不由「多数人怎么看」决定，而由**边际交易者**决定——谁是下一个买卖的人、以什么理由。

- 一致看多 → 价格已包含，不涨反跌（利多出尽）
- 一致看空 → 价格已包含，不跌反涨（利空出尽）
- 真正的机会在「市场还没定价的边际变化」

### 3. 模式转变识别
当深层宏观环境发生结构性变化时，出现**模式转变（Regime Change）**：

| 模式转变信号 | 含义 |
|---|---|
| 全球民粹主义抬头、贸易体系重构 | 自由市场假设失效 |
| 央行储备结构变化（去美元化→黄金） | 传统避险资产逻辑改变 |
| 量化策略普遍失效 | 市场微观结构变化 |
| 关税成为谈判筹码 | 政策不可预测性飙升 |
| 传统经济刺激方式失效 | 需要新的政策框架 |

模式转变期内，**历史相关性弱化、技术分析成功率下降、估值中枢漂移**。此时不能依赖历史统计规律。

## 逆共识四步法

### Step 1：识别当前共识
- 主流媒体/卖方/市场一致看什么方向？
- 价格已经反映了多少？

### Step 2：找盲区
- 共识忽略了什么？
- 哪些数据/信号和共识矛盾？
- 哪些假设可能被打破？

### Step 3：建逆共识假说
- 如果共识错了，会错在哪里？
- 什么证据能证明共识错了？
- 时间窗口多长？

### Step 4：等待边际定价者入场
- 不需要市场立刻转向
- 寻找「定价早晚会发生」的逻辑——如产能信号、政策转变、资金流向变化

## 关键指标

| 指标 | 观察内容 |
|---|---|
| **全球央行储备**（除黄金） | 储备见顶 → 标普可能见顶 |
| **黄金 vs 美元** | 央行储备去美元化速度 |
| **美国金融条件** | 收紧 → 中国离岸市场受压 |
| **北水（内地→港股）** | 领先恒指 1-2 季度 |
| **美国对华贸易余额** | 历史上领先中国股票 3-6 个月 |
| **半导体周期** | 全球科技需求先行指标 |
| **纳指隐含波动率 17 年周期** | 波动率顶峰 → 市场模式转变 |

## 2024-2025 案例：逆共识「东升西降」

| 共识 | 逆共识 | 验证信号 |
|---|---|---|
| 美国经济不会衰退（"This time is different"） | 半导体周期见顶、纳指波动率周期触发模式转变 | 2024 年纳指波动率达 17 年周期顶峰 |
| 中国持续低迷 | 中国 5% GDP 维持、财政扩张启动 | 北水持续流入港股、地方政府债务出现化解进展 |
| 港股无望 | 港股估值修复 + 北水推动 | 恒指从低点反弹创新高 |

## 风险控制

逆共识最大的风险是**共识对了而你错了**。因此：

1. **仓位限制**：逆共识仓位不超过总仓位的 20-30%。
2. **证伪条件必须清晰**：写下「什么事实出现就认错」。
3. **时间止损**：如果预期的时间窗口内无验证信号出现 → 减仓。
4. **分批建仓**：不在一个价位打满逆共识仓位。
