# 杀杠杆 / 流动性踩踏 Playbook

## 何时必读

出现以下任一场景时必须读本文件，而不是只看个股基本面：
- 用户问“这波能不能抄底 / 要不要降风险 / 是不是系统性风险 / 是不是杀杠杆”。
- 美股、纳指、SPY/QQQ、mega-cap、成长股大跌，且用户提到 `VIX`、`黄金`、`Apple/AAPL`、`长端利率`、`Skew`、`GEX`。
- 个股逻辑看起来没坏，但市场给出“好公司也一起被砍”的异常反馈。

## 核心原则

杀杠杆不是“利空变多”这么简单，而是 **资金被迫缩表 / 降杠杆 / 提保证金 / 降 VaR**。一旦进入这个 regime，
**先回答“系统还允不允许你承担风险”，再回答“这家公司值不值得买”。**

所以这层框架的优先级高于单一个股叙事：
- 它不一定推翻中线基本面；
- 但它会直接压低短线胜率、仓位上限和加仓权限；
- 它会让“低估值 / 好财报 / 龙头”都先失去执行座位。

## 六个关键特征：看到什么，代表什么，动作怎么变

| 信号 | 代表什么 | 不是啥 | 动作含义 |
|---|---|---|---|
| **1. VIX 暴涨** | 波动率冲击、vol-control/CTA/risk-parity 被动降风险，相关性开始上升 | 不是单纯“情绪差” | 降低对均值回归的信任；VIX 单独暴涨可先降一级仓位 |
| **2. 黄金与指数同跌** | 典型流动性挤兑 / 保证金补仓 / 先卖最容易卖掉的资产换现金 | 不是普通 growth scare；也不是“避险有效” | 说明跨资产同步卖出；暂停“黄金在对冲风险”的假设 |
| **3. Apple 暴跌** | 机构在卖最流动、最容易兑现的 mega-cap 领导股；被动指数权重开始反噬 | 不是普通单股利空就能解释 | 下调对指数托底、龙头先稳住的预期；反弹质量下降 |
| **4. 长端美债利率暴涨（尤其 30Y）** | term premium / 财政风险 / basis unwind / 通胀重定价；股债同时承压 | 不是健康增长信号 | 长久期资产估值受二次打击；“跌多了就该弹”要降级 |
| **5. Skew 极度左偏** | 机构在为左尾付高价，说明 crash hedge 需求很强 | 不是天然逆向做多信号 | 除非 skew 回落，否则别把单日反弹误判成底部确认 |
| **6. 指数 GEX 大规模出逃** | dealer 长 gamma 缓冲消失，指数更难被“钉”在区间里，波动容易放大 | 不是普通负 gamma 就等于出逃 | 反弹更脆，跌破关键位更容易加速；必须盯 Put Wall / Flip / 墙位下移 |

## 组合解释：为什么这 6 个一起出现时要当成 regime，而不是新闻噪音

最危险的不是任何单点，而是 **四个层面同时失灵**：
1. **波动层**：VIX 抬升，说明风险预算在主动或被动收缩。
2. **跨资产层**：黄金与指数同跌、长端利率上冲，说明“经典对冲腿”也失效。
3. **领导股层**：Apple 被砍，说明市场在卖流动性，而不是只卖垃圾资产。
4. **期权/做市层**：Skew 左偏 + 指数 GEX 外流，说明下行保护定价更贵、dealer 缓冲更弱。

当这四层里有 3 层同时亮红灯，就不能再把 selloff 当成普通回撤。

## Regime 分级（建议直接写进报告）

| 触发数 / 覆盖层数 | Regime | 含义 | 仓位/动作纪律 |
|---|---|---|---|
| 0-1 个信号 | `normal` | 常规回撤 / 局部事件 | 正常按多因子与个股逻辑决策 |
| 2 个信号 | `stress_building` | 风险预算收紧中 | 总仓先打 7 折；禁止无证据追高 |
| 3 个信号，且覆盖 ≥2 层 | `deleveraging_watch` | 杀杠杆正在形成 | 最大仓位打 5 折；暂停 L3 加仓 |
| 4 个信号，且覆盖 ≥3 层 | `active_deleveraging` | 系统性流动性踩踏 | 最大仓位打 3 折；最高只给 L0-L1，禁止激进抄底 |
| 5-6 个信号 | `forced_liquidation` | 强平/被动卖出主导 | 只谈减仓/回避/等修复；除非重新站回关键位，否则不给新多头执行 |

## 冲突裁决规则（最常用）

1. **基本面很好，但 cluster ≥3**
   - 结论：中线叙事可保留，短线执行降级。
   - 动作：不直接否定公司，只否定“现在就能重仓”。

2. **黄金不涨反跌 + 长端利率还在冲**
   - 结论：这是流动性挤兑，不是温和 risk-off。
   - 动作：把“防守资产对冲有效”的前提拿掉，仓位继续压缩。

3. **Apple 破位 + 指数 GEX 弱化**
   - 结论：领导股和 dealer 缓冲同时失灵。
   - 动作：指数/高 beta 的反弹只能先当 technical bounce，不先当趋势反转。

4. **Skew 极左，但 VIX 没继续冲**
   - 结论：尾部保护需求仍在，可能是事件前夜或恐慌余波。
   - 动作：等待 skew 回落或 GEX 稳住后再放宽仓位。

## 数据纪律：哪些能说，哪些不能乱说

### 1) “GEX 出逃”必须有时间序列对比

只有在 **同一指数、同一口径、同一到期视角** 下，看到：
- 总净 GEX 明显下降，
- 或墙位系统性下移，
- 或从正 gamma/有缓冲切到负 gamma/脆弱结构，

才可以写“GEX 出逃 / 外流”。

**只有当前一张快照时：**
- 可以写 `negative gamma proxy`、`dealer support weak`、`墙位下移`；
- **不能**直接写“今天 GEX 大规模出逃”，除非有前值对比或用户提供前后截图。

### 2) “Skew 左偏”要和价格结构联看

- 单看 skew 高，不等于马上见底或马上崩。
- 真正危险的是：**skew 左偏 + VIX 升 + Put Wall 下破 + GEX 变脆**。

### 3) “Apple 暴跌”要看相对表现

- 关注 AAPL 相对 SPY / QQQ 的跌幅、成交量、是否破关键位。
- 如果 AAPL 明显跑输大盘，优先解释为“卖流动性”，不是先解释成公司独有问题。

### 4) 自动化落地口径（推荐默认路径）

先跑：

```bash
python3 scripts/risk_regime_snapshot.py TSLA --json
```

脚本会自动：
- 抓 `^VIX`、`GLD`、`SPY`、`AAPL`、`^TNX`、`^TYX`、`^SKEW`
- 调 `options_gamma.py SPY --json` 与 `--near --json`
- 将 SPY GEX 的同口径历史快照写到 repo 外缓存 `~/.cache/hermes/trading-research/risk_regime/history/`
- 在没有前值时明确降级成 `dealer support weak proxy`

这样做的目的不是替代主观判断，而是先把“这是不是系统性 risk regime”从拍脑袋，变成可重复调用的结构化输入。

## 报告写法（建议摘要模板）

```markdown
风险 Regime：active_deleveraging（4/6）
- 触发信号：VIX 暴涨、黄金与指数同跌、Apple 跑输、长端利率上冲
- 主导解释：典型流动性挤兑，不是单纯增长担忧
- 对动作的约束：暂停 L3 加仓；新仓最高 L1；若跌破 Put Wall 未收回则不接盘
```

## 默认假设失效清单（原 market-stress-interpretation 独有段落）

给出动作等级前，先明确写出哪些默认交易假设已经失效：
- 均值回归
- 避险腿有效
- 龙头先稳
- 股债对冲有效
- dealer 长 gamma 减震器有效

## 三种主导机制判读（原 market-stress-interpretation 独有段落）

六信号不是机械打分题，重点不是"触发了几个"，而是哪种系统性失灵在主导：

### A. 流动性挤兑 / 保证金补仓型
常见组合：VIX 暴涨 + 黄金与指数同跌 + Apple 暴跌。
解释：市场在卖最容易卖的资产换现金，先别把下跌解释成基本面重估。
动作约束：暂停"优质资产先企稳"的假设；反弹先按 technical bounce 处理；默认不升级动作等级。

### B. 长久期杀估值 / 股债同时失灵型
常见组合：长端利率暴涨 + 高估值成长承压 + 黄金不提供缓冲。
解释：不是普通 risk-off，而是折现率与对冲腿同时出问题。
动作约束：下调高估值、长久期、久现金流资产的仓位上限；不用"利率上去金融股受益、市场会自稳"这种过度简化叙事。

### C. 左尾定价上升 / dealer 缓冲衰减型
常见组合：Skew 左偏 + GEX 走弱/转负 + 关键位失守。
解释：市场在买 crash hedge，同时 dealer 的减震器变薄。
动作约束：Put Wall / Gamma Flip / strike 迁移优先于主观抄底；单日反弹不足以宣布见底。

> 若三类解释同时成立，默认按 `active_deleveraging` 或更高处理，除非至少两个系统信号先修复。

## 报告输出要求（原 market-stress-interpretation 独有段落）

最终结论里必须显式写出：
1. 当前属于 `normal / stress_building / deleveraging_watch / active_deleveraging / forced_liquidation` 哪一档；
2. 主导机制是哪一种（可多选，但要有主次，参见上方 A/B/C）；
3. 哪些默认假设已经失效（参见上方清单）；
4. 什么修复信号出现后，才允许升级动作等级。

若缺少第 3、4 项，结论默认不合格。

修复信号判定：至少同时满足两类才能认定修复中——波动/Skew 缓和、Gamma/Put Wall 修复、跨资产抛压停止、领导股不再被卖流动性。

## 和个股逻辑怎么拼接

- 先定 regime，再评估个股。
- 若 regime = `active_deleveraging` 或 `forced_liquidation`：
  - 先用它限制仓位和动作上限；
  - 再看个股基本面决定“以后要不要回来”，而不是“现在能不能重仓”。
- 若 regime 只到 `stress_building`：
  - 个股仍可做，但必须让宏观/结构 EID 参与仓位计算，不能只靠财报和题材分。
