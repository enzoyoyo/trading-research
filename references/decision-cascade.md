# 分级决策级联（Decision Cascade）

> 从证据到行动的严格转化链。每一级有明确的升级/降级条件，不得跳级。

## 决策级联图

```
   数据不足 / 信号冲突
     ↓
  L0 观察 ───(数据充实)→ L1 试错 ───(证据收敛)→ L2 建仓
    ↑                      │  ↑                    │
    │                      │  └─── falsifier ──────┤
    │                      ↓                        ↓
    └────── 持续缺口 ←── L4/L5 ←── falsifier ←── L3 加仓
                        减仓/回避
```

## 各级详细触发/退出条件

### L0：观察（最高风险值：无）

**进入条件：** 任何标的初始状态、或 L1+ 降级回来
**可升级到 L1：** 完成身份解析 + 至少 3 个独立 EID 且其中 2 个同向
**不可升级：** 关键数据缺口未解决、冲突未裁决
**输出要求：** 不写仓位建议，只写"需要看什么"和"什么时候再看"

### L1：试错（最高仓位：基准仓位的 30%）

**进入条件：** 证据初始浮现（3+ EID，2 同向），但核心数据有缺口
**可升级到 L2：** 财报/公告验证叙事、市场结构确认（A股突破关键位/港股成交额回升/美股站上 Put Wall）
**必降级到 L0：** falsifier 触发、新冲突产生且难裁决
**必降级到 L4：** 结构破位、宏观 shock、流动性死亡
**输出要求：** 小仓位、紧止损、短 review clock（≤3 个交易日）

### L2：建仓（最高仓位：基准仓位 × 数据质量倍率上限）

**进入条件：** 4+ EID 同向（含基本面 1+、市场结构 1+）、冲突已裁决、falsifier 明确
**可升级到 L3：** 新财报/公告/订单强化叙事、关键位放量突破
**必降级到 L1：** 市场结构走弱但基本面未破
**必降级到 L4：** 基本面恶化、falsifier 触发、宏观逆转
**输出要求：** 常规 review clock（每周）、移动止损位

### L3：加仓（最高仓位：在 L2 上限基础上追加）

**进入条件：** 全新证据强化原叙事（营收加速/估值重定价/新产品/政策加持）、市场给予确认信号
**必降级到 L2：** 估值达到极高水平（A 股 PE > 历史 90%分位、美股 > 行业 95%等）
**必降级到 L4：** 边际恶化、盈利预警、监管风险、内幕减持
**输出要求：** 加仓额度不超过 L2 上限的 50%、设定逼空/逼多退出条件

### L4：减仓/止盈（当前仓位的 50-100% 退出）

**进入条件：** falsifier 触发、结构破位、估值极端、宏观逆风升级
**可升级回 L2：** 结构性修复（关键位重新站回、财报证伪看空叙事）
**不可等待：** 跌破 Put Wall、流动性枯竭、强制退市 → L5

### L5：回避（仓位必须为 0）

**进入条件：** 结构崩塌、流动性死亡、强制退市、司法风险、基本面靠前已破
**不可逆回：** 在结构修复、风险出清前不得返回
