# Serenity Method · 产业链瓶颈框架（v2.0 完整版）

> 参考 Serenity 公开方法论（@aleabitoreddit）+ serenity-skill 仓库。核心命题：AI 超级周期 = 一系列 supply bottleneck 的轮番爆发。**谁卡脖子，谁涨。**
>
> 不找需求最强的公司，找**供给弹性最差**的环节。

---

## 一、哲学内核

不做表层 AI（NVDA/MSFT/META），专注二阶、三阶、四阶传导。越往上游：市值越小、覆盖越少、弹性越大、波动越大。

### 四原则
1. **Supply Elasticity 优先**：扩产周期越长越好（InP 衬底 18-24 月 vs 光模块组装 3-6 月）、寡头垄断、技术/良率壁垒、产能集中、客户验证周期长。
2. **产业链 N 阶传导**：一阶 hyperscaler capex → 二阶 光模块/HBM/封装 → 三阶 光芯片/InP衬底/DSP/硅光代工 → 四阶 材料(磷化铟/锗/ABF膜)/设备。
3. **主题轮动 + 产业验证**：确认进入「加速区」→ 高 conviction 重仓；瓶颈缓解信号出现 → 切换下一个瓶颈。非「买入持有」。
4. **Narrative Amplification**：用产业链逻辑讲故事会制造拥挤交易——既是 alpha 来源也是风险来源。

## 二、9步深度研究流程

### Step 1：定范围
- 市场：A/H/美/台/日/韩/欧/全球
- 主题：AI 基建、半导体、CPO、机器人、电力、材料、设备、医疗制造、国防电子等
- 时间窗口：「现在」= 3-12 个月，除非明确其他

### Step 2：叙事转系统变化
```
需求浪潮 → 系统压力 → 必需的技术变化 → 受限层
```
问：什么技术/经济约束正在变得更难规模化？哪个物理约束最重要（功率/延迟/带宽/热量/良率/纯度/可靠性/周期时间/封装密度/法规/电网接入）？

### Step 3：画产业链地图
```
终端需求 → 系统集成商 → 模块/子系统 → 芯片/器件 → 工艺/封装/测试 → 设备/检测 → 材料/耗材 → 物理基础设施
```

### Step 4：找稀缺层
稀缺层的叠加信号：
- 客户离开它无法规模化
- 供应商数量少
- 认证周期长
- 扩产需要专用设备/许可/工艺/材料纯度
- 客户表现出紧迫感（预付款、产能预订、长约、加急订单、接受涨价）
- **公开市场仍按旧业务分类给这家公司定价** ← 这是超额收益来源

先排层级，再排公司。

### Step 5：建候选池
- 至少 20 家候选（市场足够大时）
- 覆盖：明显赢家、算力芯片、EDA/IP、内存互连、设备、工艺专用工具、材料耗材、封测、PCB/CCL/光链路、基础设施
- 分桶要细：不要把算力芯片、EDA/IP、内存互连、设备、材料、封测、光链路、PCB/CCL 混在一个候选层

### Step 6：收集当前证据
目标 25+ 来源的合理组合：
- 10+ 申报/交易所披露/年报/季报/公告
- 5+ 公司 IR/transcript/产品/技术资料
- 5+ 权威媒体/行业期刊/协会/专利/标准
- 额外来源交叉验证估值、流动性、融资、客户

证据分级见 `references/evidence-ladder.md`。曾计划的 radar cache 自动化通道（`scripts/serenity_overlay.py`）已移除——它从未有生产者写入缓存，长期只返回 `unavailable`；Serenity 判断走本节的手动证据收集流程。

### Step 7：排名
排名维度：需求压力 > 稀缺层紧度 > 供应商集中度 > 扩产难度 > 证据强度 > 估值错配 > 近期催化

**两层排名必须分开**：
1. **层级排名**：产业链哪些层值得优先关注
2. **公司排名**：哪些公司最能代表这些层级且有证据

每个最终候选回答：
- 它卡住什么环节？
- 在产业链什么位置？
- 为什么排这个位置？
- 什么证据支撑？
- 什么会让排名下降？

### Step 8：解释可能出错的地方
- 替代供应商认证加速
- 竞争对手更快扩产
- 需求疲软
- 稀释/融资
- 利润率差
- 公司治理
- 地缘政治
- 客户流失
- 估值已透支

### Step 9：给出下一步
具体检查项：申报文件、特定指标、客户交叉验证、产能证据、合同证据、估值对比、近期关注事件。

## 三、瓶颈紧张度评分（1-5）

| 分 | 状态 | 典型信号 |
|---|---|---|
| 5 | 严重短缺 | 涨价>30%、交期翻倍、客户预付锁产能、股权投资绑定 |
| 4 | 明显紧张 | 产能利用率>90%、开始涨价、LTA 签订加速 |
| 3 | 偏紧 | 个别客户缺货、lead time 小幅延长 |
| 2 | 平衡 | 供需匹配、价格稳定 |
| 1 | 宽松 | 产能利用率<70%、价格下行 |

**此评级是 Bottleneck Scorecard 中 `chokepoint_severity` 的定性基础。**

## 六、研究伙伴协议（Research Partner Protocol）

当用户想讨论/学习/压测想法时，角色定位：**直接的研究伙伴，迫使想法从叙事走向证据。**

### 对话循环
1. 陈述当前判断
2. 指出缺失环节
3. 提一个聚焦问题
4. 用回答深入一层
5. 持续回到：稀缺层、证据、估值、什么会出错

### 问题库
- 系统里到底变了什么？
- 哪一层先变得难以规模化？
- 为什么这家公司难以被替代？
- 什么公开证据表明客户现在就需要？
- 这家公司是控制稀缺层，还是只受益于主题？
- 收入结构显示业务在变化吗？
- 毛利显示定价权吗？
- 应收、存货、capex在讲不同的故事吗？
- 什么事实出现会立即降级判断？
- 下一步该查什么来源？

### 当用户兴奋时（拉回证据）
> "这个方向有研究价值，但现在最弱的是证据。你还没证明它控制的是产业链卡点，也没证明客户短期绕不开它。"

### 当证据弱时（直接说）
> "这个现在更像线索，还没到高优先级。先查客户认证、收入结构和产能证据。"

## 七、决策规则

- 瓶颈强(4-5) + 供给弹性差 + 订单/长约/涨价验证 + 估值未透支 → 高 Serenity 权重
- 只有概念、没有订单/财报验证 → 只能观察
- 供给快速释放、价格下行、替代技术路线突破 → 叙事降级

## 八、固有风险

高波动（小市值+热门，单日±20%正常）、Narrative 依赖（risk-off 跌幅极大）、拥挤交易、技术路线被绕过、hyperscaler capex 周期性削减。
