# A-Share Short-Term Layer · A股短线交易层

> 参考新生代作手课程体系（软件使用→右侧买点→仓位管理→止盈→买点重塑→做T→潜伏战法→层次思维→复盘）。专为 A 股 T+1、涨跌停制度设计，不与美股/港股的 Serenity 框架混用。

## 核心理念

A 股短线不是「看图赌博」，而是**情绪周期 + 资金结构 + 筹码分布**的三维博弈。所有买点在右侧（趋势确认后），所有决策围绕「赔率×胜率×仓位」。

## 一、右侧买点体系

**铁律：不抄底，只做右侧确认。**

| 买点类型 | 触发条件 | 止损位置 |
|---|---|---|
| **突破买点** | 放量突破关键阻力位（前高/均线/密集成交区） | 突破位下方 3% |
| **回踩买点** | 突破后回踩不破，再次放量上攻 | 回踩低点下方 2% |
| **均线买点** | 回踩 20MA/60MA 不破，出现止跌K线 | 均线下方 3% |
| **情绪冰点买点** | 恐慌性杀跌后成交量萎缩+出现下影线 | 当日最低价下方 2% |

**关键纪律**：
- 买点不是「感觉」，是**明确的 K 线信号**（放量+形态）
- 永远在买入时设止损，不设止损就不买
- 同一标的连续 2 次止损 → 停 1 周不碰

## 二、仓位管理

```
总仓位 = 市场温度系数 × 信号强度系数 × 基础仓位
```

| 市场阶段 | 温度系数 | 单票上限 |
|---|---|---|
| 牛市/主升 | 1.0 | 30% |
| 震荡/结构性 | 0.7 | 20% |
| 下跌/熊市 | 0.3 | 10%（或不参与） |

| 信号强度 | 强度系数 | 初始仓位 |
|---|---|---|
| 多重共振（技术+资金+板块联动） | 1.0 | 满计划仓位 |
| 单一信号 | 0.5 | 半仓先试 |
| 模糊信号 | 0.2 | 观察仓（≤5%） |

**金字塔结构**：
1. 初始试仓（30% 计划仓位）→ 验证
2. 确认加仓（+40%）→ 顺势
3. 最后加仓（+30%）→ 加速段（风险最高，谨慎）

**不要做的事**：
- 越跌越补（补仓只在右侧确认后）
- 单票一次打满（永远分批）
- 无视大盘环境满仓干（覆巢之下无完卵）

## 三、止盈规则

| 类型 | 规则 |
|---|---|
| **分批止盈** | +10% 卖 1/3，+20% 再卖 1/3，剩余看趋势 |
| **移动止盈** | 从最高点回撤 8% 全出（或跌破 10MA） |
| **时间止盈** | 建仓后 5 个交易日未达预期 → 减半仓 |
| **涨停板止盈** | 连板股开板即走，不赌回封（回封可再进） |
| **催化落地上盈** | 利好兑现但股价不涨反跌 → 全出 |

## 四、层次思维

A 股短线永远有「主线→支线→补涨」三层传导：

| 层次 | 特征 | 策略 |
|---|---|---|
| **主线** | 资金共识最强，涨幅最大，最先启动 | 重仓跟随，不做预测 |
| **支线** | 主线扩散的同板块/同逻辑股 | 中等仓位，等主线封板后介入 |
| **补涨** | 前期未涨、逻辑相关但被忽视 | 轻仓埋伏，不追高 |

**判断主线的方法**：涨停数最多/连板高度最高/成交量最大/政策催化最强的板块 = 主线。

## 五、筹码分布分析

| 筹码状态 | 含义 | 操作 |
|---|---|---|
| 低位密集 | 主力在建仓 | 观察，等右侧信号 |
| 拉升中筹码松动 | 部分资金出货 | 减仓或设紧止损 |
| 高位密集 | 主力在派发 | 不追，有持仓逐步止盈 |
| 双峰结构 | 上方套牢盘压力大 | 等筹码下移再考虑 |

## 六、复盘体系（每日）

1. **大盘环境**：成交量变化、涨跌比、涨停/跌停数、炸板率
2. **主线梳理**：当日最强 3 个板块，龙头是谁，梯队是否完整
3. **个股回顾**：持仓股的买点是否有效、卖点是否合理、有没有违背纪律
4. **错失机会**：看好但没买的，为什么没买？是犹豫还是纪律？
5. **明日计划**：哪些信号触发就行动，哪些情况暂停交易

## 七、做T策略（T+1 制度下的持仓优化）

做T 是利用 A 股 T+1 制度（当日买入次日才能卖出）在已有持仓上做日内差价。**前提**：已有持仓，才做T；不持有不做T。

| 做T类型 | 操作 | 适用场景 |
|---|---|---|
| **正T（先买后卖）** | 开盘买入 → 拉升后卖出等量原有持仓 | 判断当日有大幅拉升，早盘低开/平开 |
| **倒T（先卖后买）** | 开盘卖出等量 → 下跌后买回 | 判断当日有大幅下跌，早盘高开/冲高 |
| **滚动T** | 日内多次正T/倒T组合 | 高波动日，熟练者专用 |

**做T纪律**：
- 单次做T仓位不超过持仓的 30%（做错了可以止损）
- 做T不是为了赚差价，是为了**降低持仓成本**
- T飞了（卖了买不回来）不要追——宁可错失不要追高
- 不做T的日子比做T的日子多——只在明确波动信号时做
- 尾盘 14:30 后不做T（时间不够、风险失控）

## 八、短线潜伏战法

潜伏 = 在催化事件发生前提前埋伏，不等拉升再追。本质是**用时间去换确定性的催化溢价**。

| 潜伏类型 | 触发逻辑 | 建仓时机 | 止盈时机 |
|---|---|---|---|
| **业绩潜伏** | 预判财报超预期 | 财报前 5-10 交易日 | 财报公布次日（利好兑现即走） |
| **政策潜伏** | 政策文件/会议前夕 | 政策窗口前 1-2 周 | 政策出台当日/次日 |
| **事件潜伏** | 行业大会/新品发布/招标 | 事件前 3-5 交易日 | 事件发生当日 |
| **困境反转潜伏** | 利空出尽+基本面改善信号 | 利空消化后缩量横盘 | 等右侧放量确认后分批出 |

**潜伏纪律**：
- 不超过总仓位的 15%（不确定性高于右侧）
- 时间止损：潜伏窗口过后无催化 → 无条件走人
- 不潜伏没有明确催化时间的题材
- 利好兑现不涨反跌 → 立即清仓（说明市场已提前定价或利好不及预期）
- 潜伏前必须写：催化事件、预期时间、证伪条件

## 关键纪律（A 股特有）

- **交易规则 freshness gate**：A 股短线/执行判断必须按“交易所 + 日期”刷新制度，不把旧版 T+1/涨跌停/ST 规则当静态常量。已核验上交所《上海证券交易所交易规则（2026年修订）》自 **2026-07-06** 起施行：沪市盘后固定价格交易扩至全部 A 股和交易型开放式基金；基金收盘阶段由连续竞价调整为收盘集合竞价；沪市主板风险警示股票涨跌幅限制由 5% 调整为 10%。影响范围只限交易时段、撮合/收盘价形成、涨跌停与滑点/流动性假设；**不得因此单独提高 action level 或 position cap**。分析深市/北交所或跨交易所组合前，必须回抓对应交易所原文，不得把沪市规则直接套用。
- **T+1 铁律**：上午买要留足下午的余地，不追涨超过 5% 的票（当日被套无法止损）
- **涨跌停限制**：一字板买不到不排，开板后看承接再决定
- **ST/退市风险**：不做 ST、不做有退市风险的票，哪怕赔率再高
- **龙虎榜利用**：机构买 > 游资买 > 散户买。纯散户榜不要追。
- **炸板率**：当日炸板率 > 40% → 市场极弱，不做打板

## 与长期框架的分工

| | A 股短线层（本文件） | 长期框架（Serenity/刘备/洪总） |
|---|---|---|
| 时间维度 | 日-周 | 月-年 |
| 决策驱动 | 情绪周期+资金结构+筹码 | 产业链瓶颈+估值+业绩逻辑 |
| 适用市场 | A 股 | A/H/美股通用 |
| 仓位思维 | 金字塔分批 | 逻辑驱动的集中配置 |

**互不冲突**：短线层只在你明确要求做 A 股短线/打板/右侧时触发。其他场景默认走长期研究框架。
