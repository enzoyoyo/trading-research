# Early-Stage Theme Quality Framework · 早期主题质量评分

> 适用于萌芽期/商业化导入初期的技术主题。当传统 Quality/Growth/Value 框架因"无盈利、无稳定营收、无历史数据"而失效时，使用本框架。与 `unified-research-framework.md` 中的 7 模块评分互斥——早期主题用本框架，成熟公司用传统 7 模块。

## 触发条件

必须同时满足以下至少 3 项才启用本框架：
- 行业处于萌芽期或商业化导入初期（首个量产线尚未建成或在建中）
- 多数标的营收规模极小或无相关业务收入
- 行业 CAGR 预期 >30%
- TAM 高度不确定（不同来源差距 >2x）
- 技术路线未收敛，多方博弈

## 四维度评分

| 维度 | 权重 | 核心问题 | 满分标准 |
|---|---|---|---|
| 1. 结构性赛道 | 30% | CAGR≥15%？公司是否直接受益于结构性浪潮？ | 5分：CAGR 50%+，公司是核心瓶颈环节 |
| 2. 竞争格局 | 25% | 公司在细分市场是否前3？CR3>50%？ | 5分：全球前2，市占率>30%，技术不可替代 |
| 3. 供给侧定价权 | 20% | 毛利率/净利率是否稳定或提升？有 ASP 定价权？ | 5分：毛利率>50%，净利率>20%，ROE>15% |
| 4. 市值-TAM 错配 | 25% | 市值/TAM <2%？ | 5分：市值/TAM <2%；4分：2-5%；0分：>100% |

### 评分细则

**维度1：结构性赛道**
| 得分 | 标准 |
|---|---|
| 5 | 公司处于 CAGR 50%+ 赛道的核心瓶颈环节，有可验证的产业趋势支撑 |
| 4 | CAGR 30-50%，公司直接受益 |
| 3 | CAGR 15-30%，间接受益 |
| 2 | CAGR 5-15%，关联度弱 |
| 1 | CAGR <5% 或关联度极弱 |

**维度2：竞争格局**
| 得分 | 标准 |
|---|---|
| 5 | 全球前2，技术路线不可替代，有专利/认证壁垒 |
| 4 | 全球前3，有差异化优势 |
| 3 | 前5，面临激烈竞争 |
| 2 | 有独特技术但市场份额极小 |
| 1 | 无明显竞争壁垒 |

**维度3：供给侧定价权**
| 得分 | 标准 |
|---|---|
| 5 | 毛利率>50%，净利率>20%，ROE>15%，ASP持续提升 |
| 4 | 毛利率>40%，净利率>10% |
| 3 | 毛利稳定在30-40%，有定价权证据 |
| 2 | 毛利率波动大（±15%）或持续下降 |
| 1 | 毛利率<20%，持续亏损 |

**维度4：市值-TAM 错配**（本框架最关键的维度）
| 得分 | 标准 |
|---|---|
| 5 | 市值/TAM（2030E）<2%——极高错配，multi-bagger潜力 |
| 4 | 市值/TAM 2-5%——良好错配 |
| 3 | 市值/TAM 5-15%——中等 |
| 2 | 市值/TAM 15-50%——有限上行空间 |
| 1 | 市值/TAM 50-100%——已定价大部分预期 |
| 0 | 市值/TAM >100%——TAM已完全反映甚至过度反映 |

## 准入阈值

| 总分 | 含义 | 动作 |
|---|---|---|
| ≥15 | 高质量早期标的 | 可进入 L1-L2 决策级联 |
| 10-14 | 有结构性优势但存在明显短板 | 仅 L1 试错，不可重仓 |
| <10 | 主题纯度过低或基本面过弱 | L0 观察或回避 |

### 硬性准入标准
- **维度4 ≥ 4**：市值必须有显著错配空间
- **维度1 ≥ 4**：必须是直接受益于结构性浪潮
- **无重大合规/财务风险**

## 核心方法论洞察：未达阈值本身是信息

当整个候选池没有任何标的达到 15/20 时，这不是框架的"失败"，而是重要的市场信息：

1. **市场尚未准备好为这个赛道定价**——当前公开市场参与者要么财务基本面未反映远期叙事，要么市值已远超当期 TAM
2. **这是 VC 式的公开市场机会**——需要接受"非对称回报必须容忍低 Quality 评分"的现实
3. **行动含义**：
   - 如果以该主题建仓，需容忍低 Quality 评分
   - 大资金可能缺乏合适的建仓工具（最纯粹的标的市值太小/流动性太差）
   - 等待阈值被突破本身就是一个投资时机信号

## 极早期赛道投资的特殊规则

1. **维度3（定价权）天然低分是正常的**——营收未兑现，毛利率/净利率无意义
2. **维度4（市值-TAM错配）是最核心的 alpha 来源**——极早期赛道赚的是认知差
3. **先行指标比财务数据更重要**——设备订单、产能建设、客户认证进度等
4. **技术路线风险是最大的风险**——如果技术路线被证伪，所有前期定价归零

## 与传统 7 模块评分的切换规则

```
标的/赛道成熟度判断
├── 萌芽/导入初期 → 使用本框架（4维度）
├── 成长/扩散期 → 混合使用（本框架 + 传统7模块各50%权重）
└── 成熟/寡头期 → 使用传统7模块（unified-research-framework.md §7）
```

## 数据完整性要求

本框架中大量数据为[待验证]状态是常态而非缺陷。关键纪律：
- TAM 估算必须标注来源和不确定性区间
- "CAGR 50%+"等数据必须注明基准年、目标年和假设
- 维度4的市值/TAM 计算必须显式写出 TAM 来源
- 当 TAM 估算来源不唯一时，取保守值（较高 TAM → 较低得分）
