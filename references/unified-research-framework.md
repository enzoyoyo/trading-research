# 统一智能投研框架

## 0. 投研哲学

1. **先排雷，后找机会**：财报逻辑、数据新鲜度、流动性、制度风险不过关，不进入看多讨论。
2. **叙事不是故事，是估值函数**：市场买的是终局天花板；财报只是验证叙事是否兑现。
3. **短线看情绪，中线看叙事，长线看现金流与供给格局**。
4. **好的交易不是观点正确，而是座位合法**：赔率、位置、流动性、证伪条件同时成立才可行动。
5. **方法论可迁移，制度不可乱迁移**：A 股涨跌停/连板/龙虎榜只适用于 A 股；美股更看 guidance、capex、SEC、供应链；港股更看流动性、南向和折价修复。
6. **对任何新兴主题，先做认知分叉，再做分析**：同一个材料名称/技术名词可能对应两个截然不同的投资命题。混为一谈是新兴主题投资中最常见的认知谬误。见 `theme-cognitive-fork.md`。
7. **价格无公式，只是买卖双方的成交。先画参与者图谱再走方法论**（Step 0）：每只股票由一群结构相对固定的参与者构成；他们的动机随信息输入此消彼长。在戴维斯双击、Serenity、Capex 轮动之前，先回答——谁是边际买卖双方？他们的信念多强？什么改变了他们的逻辑？见 `participant-flow-motivation.md`。

## 0a. 强制双链

- 研究链：`宏观 → 行业 → 公司 → 情绪 → 资金结构 → 机会`。每层输出 `state/as_of/evidence_ids/data_gaps/implication`；缺层只降级，不得由后层分数补回。
- 决策链：`机会 → 评分 → 概率 → 风险 → 计划`。概率必须可结算并按 horizon 分账；计划必须含共识/价格贴现/差异观点、至少 3 条 premortem、触发、失效与 `no_trade_if`。
- `scripts/research_run.py --query-type ...` 暴露机器可验的链路骨架；它是编排合同，不是假装已抓取证据。最终动作仍由 Decision Compiler 裁决。

## 1. 五层证据链

> 五层证据链之上必须叠加 `top-down-broker-decision-framework.md` 的七层决策栈。五层负责“公司和交易本身是否成立”，七层负责“在新闻/政策/宏观/账户座位下是否值得行动、仓位上限是多少”。
> 升级版要求：所有会改变仓位的事实必须先进入 `Evidence Ledger` 并获得 EID；再进入假设账本、冲突账本和仓位上限计算器。具体合同见 `intelligent-research-contract.md`。

| 层级 | 问题 | 必查证据 | 亮红处理 |
|---|---|---|---|
| 事实层 | 数据是否真实、新鲜、完整？ | 行情、公告、财报、成交额、时间戳、来源 | 数据缺口重大 → 不下判断或降级观察 |
| 叙事层 | 市场到底在买什么？ | 核心叙事、终局利润、行业空间、催化 | 叙事模糊/已透支 → 不追高 |
| 财报层 | 叙事能被报表验证吗？ | 五大指标、一致性检验、现金流、应收/资产效率 | 报表矛盾 → 一票否决 |
| 交易层 | 资金是否在同向确认？ | 量价、趋势、主线地位、情绪周期、资金流 | 退潮/放量派发/缩量冲高 → 降仓或回避 |
| 执行层 | 现在是否有合法座位？ | 赔率、仓位、止损、证伪、复盘时钟 | 无止损/无触发/赔率差 → 不交易 |

## 2. 华源叙事 + 财报验证

- 叙事识别：AI、国产替代、出海、消费复苏、资源瓶颈、资产重估、并购重组等。
- 终局估值：**PE = f(天花板高度 m, 折现率 r)**，m = 终局利润/当前利润，与短期增速无必然关系。折现率 A 股 ~10%（牛市成长 7%、防御 6.7%、美股 8%）。不迷信历史 PE 分位。
- 阶段判断：萌芽、扩散、共识、拥挤、证伪。横着拔估值=基本面(Alpha)；竖着拔估值=流动性(Beta，防 A 型暴跌)。反景气度：增速高但天花板降=景气度陷阱。资产负债表为核心，利润表最不重要，先排雷后找机会。

五大指标（**看个股在全 A 的分位数趋势最重要**）：
1. 回款周期：应收账款周转率 + 毛利率（周转率↓不应伴毛利率↑）。
2. 再投资质量/跑冒滴漏：收入 /（固定资产 + 无形资产）。
3. 产业链地位：营运净资本占比（龙头应低/下降）。
4. 真实盈利：经营现金流净额 / 总资产。
5. 预测稳定性：一致预期利润 vs 实际利润。

精确折现率/拍卖机制/杠铃/贝叶斯沙盘见 `trading-laws.md`。

## 3. Serenity 供应链瓶颈 + Supply Chain X-Ray

### Serenity（宏观层）
适用于美股、AI 链，也可映射 A/H 的产业链标的。判断顺序：需求源 → N 阶传导 → 供给弹性 → 订单/长约/涨价/交期验证 → 拥挤风险。

### Supply Chain X-Ray（微观层）
当 Serenity 识别出瓶颈环节后，用 X-Ray 做公司级映射：L0→L4 层级、置信度分级、投资逻辑分层（技术瓶颈/战略伙伴/既有供应商延伸/必要但不敏感/纯概念）。见 `supply-chain-xray-playbook.md`。

两者的协作：
```
Serenity → "哪个环节最紧张"
X-Ray   → "谁是这个环节的具体标的"
Quality → "这些标的中哪个最值得配置"
```

### 先行指标
适用于萌芽期/导入初期赛道。当财务数据尚不能验证叙事时，先行指标是最重要的基本面证据。见 `leading-indicators-framework.md`。

## 4. A 股短线 / 游资复盘

情绪周期、主线辨识度、弱转强/分歧转一致只能作为 A 股特定制度下的观察标签。历史材料中的固定“赢面—仓位”、满仓、固定止损百分比与大师式经验数字不再作为本框架规则；它们未经本账户与样本外校准，不能覆盖波动率、流动性、账户约束或 Decision Compiler。候选仍须走证据链、风险门与可结算预测合同。

## 5. 威科夫 / 利弗莫尔 / 因子

- 威科夫：先定阶段，重点看努力与结果是否匹配。
- 利弗莫尔：顺最小阻力方向，关键点试探，错了就认。
- 因子：用于中线/组合/多标的排序，不用于编造短线买点。

## 6. 自上而下覆盖层

| 覆盖层 | 看什么 | 处理原则 |
|---|---|---|
| 实时新闻/事件 | 72小时新闻、公告、财报日历、发布会、诉讼/监管节点 | 只纳入会改变收入、利润、现金流、估值或交易窗口的信息 |
| 政策/监管 | 利率、关税、补贴、出口管制、产业政策、交易所问询 | 政策逆风只能降仓；政策顺风必须公司层面验证 |
| 宏观/流动性 | 美债名义/实际利率、美元、黄金、SPX、通胀、风险偏好 | 风险收缩时下调仓位倍率，不因个股叙事强而忽略 |
| 微观基本面 | 收入、毛利、现金流、应收、资产效率、guidance、估值 | 决定能否中线持有；报表矛盾是一票否决 |
| Longbridge/IBKR座位 | Longbridge 行情/期权链；IBKR 持仓/成本/现金/保证金（只读） | 决定真实执行上限；缺账户数据时只能给一般仓位上限 |

## 7. 评分边界

本文件不再维护第二套固定权重或“分数→动作”映射。解释性评分统一走 `multi-factor-evidence-synthesis.md` / `entry_score.py`，且只表达 evidence readiness；早期主题筛选走 `early-stage-theme-quality-framework.md`，其中任何经验阈值都必须按当前市场证据重填。评分、候选池排名和完整高分均不得提高动作等级或仓位，唯一动作权威是 Decision Compiler。

## 8. 红线

- 数据源无法验证，关键数值缺失。
- 财报逻辑明显不自洽。
- 叙事已经拥挤且估值透支终局。
- A 股退潮期还想追高。
- 放量滞涨/派发结构明显。
- 没有证伪条件、没有止损、没有复盘时钟。
- 把 Longbridge/IBKR 当成已抓取但实际没有只读数据。

## 9. OKX 适配纪律（v2.48）

- OKX 公共行情、账户只读状态与执行监督只作为 Evidence/ModuleSignal 输入；完整契约见 `okx-research-execution-supervision.md`。
- Unified Tokenized Stocks 必须先过产品身份、地区资格与 wrapper 风险门；自然语言公司名不得直接变成 `instId`。
- `entry_score.v1` 只把既有证据压缩为可解释 0–100 展示分；缺关键因子不发布总分，且分数不能替代 `scripts/decision_compiler.py`。
- 连接陈旧、账实漂移、订单未知或策略失去心跳时，只允许收紧到观察/阻断，不得用最后有效值伪装 live。
