# Theme Cognitive Fork · 主题认知分叉

> 任何新兴技术主题分析的第一步。在进入供应链映射、Quality 评分、先行指标之前，必须先完成认知分叉——同一个材料名称、同一个技术名词，可能对应两个截然不同的投资命题。

## 触发条件

每次面对新兴主题时必须执行，尤其是：
- 主题涉及一种"材料"或"技术名词"而非具体公司名
- 市场上有不同公司在讲同一个故事但商业模式完全不同
- 用户问"这个赛道怎么看"而非"这家公司怎么看"

## 两个世界框架

| 维度 | 旧世界（成熟市场） | 新世界（新兴市场） |
|---|---|---|
| 技术本质 | 已知技术的延续/改进 | 新技术范式的创建 |
| 市场阶段 | 成熟/寡头 | 萌芽/碎片化 |
| 增长驱动 | 渗透率提升、面积增长 | 技术替代、新需求创造 |
| CAGR | 3-5% | 50%+（低基数） |
| 定价权 | 寡头锁定（CR3>50%） | 未形成，多方博弈 |
| 投资逻辑 | 价值+分红 | 成长+非对称回报 |
| 典型估值 | PE 15-25x | 早期：无盈利 / PS 3-10x |
| 关键风险 | 周期波动、替代风险 | 技术路线未定、商业化时点不确定 |

## 执行步骤

### 步骤1：名称解构
- 这个"名词"在产业中到底有几个含义？
- 列出每个含义对应的：技术路径、市场规模、增长阶段、主导公司

### 步骤2：认知分叉判断
```
如果同一名词指向 ≥2 个不同产业 → 必须分开分析
如果混为一谈 → 标注"认知谬误"并解释为什么不同
```

### 步骤3：命题定性
- 旧世界命题：价值/分红/CAGR 3-10%/寡头/成熟
- 新世界命题：成长/非对称/CAGR 30%+/碎片化/萌芽
- 混合命题：公司同时横跨两个世界（如 Corning = 显示玻璃（旧）+ 光通信 + 半导体玻璃（新））

### 步骤4：选择分析框架
- 旧世界 → 传统 Quality/Growth/Value 框架
- 新世界 → 进入 `early-stage-theme-quality-framework.md` + `supply-chain-xray-playbook.md`
- 混合 → 分部估值，分别用不同框架

## 经典案例

### 玻璃基板
| | 显示面板玻璃基板 | 半导体玻璃芯基板 |
|---|---|---|
| 市场规模 | $15-20B（稳态） | <$1B 当前，$3-8B（2030E） |
| CAGR | 3-5% | 50%+ |
| 主导公司 | Corning（>50%市占） | 碎片化，无主导者 |
| 投资逻辑 | 价值+分红 | 成长+非对称 |
| 典型标的 | GLW（$153B 市值） | LPKFF（$571M 市值） |

→ 混为一谈会导致：用 GLW 的 PE 84x 去判断"玻璃基板赛道太贵"——但 GLW 的估值由光纤/AI 数据中心驱动，半导体玻璃基板几乎未被定价。

### 其他可迁移案例
- "碳化硅"：功率器件（新）vs 磨料/耐火材料（旧）
- "量子计算"：超导/离子阱/光量子（不同技术路线，完全不同的供应链）
- "固态电池"：氧化物/硫化物/聚合物（不同材料体系，不同供应链）

## 输出格式

```markdown
## 认知分叉检查

**主题名称：** [X]
**分叉结果：** 发现 [N] 个不同产业命题

### 命题A：[名称]
- 技术本质：...
- 市场阶段：成熟/萌芽/...
- 投资逻辑：价值/成长/混合
- 核心标的：...
- 适用框架：...

### 命题B：[名称]
- （同上）

### 关键结论
- 这两个命题 [是/不是] 同一个投资主题
- 混为一谈的风险：...
- 本报告聚焦：命题 [A/B]
```

## 纪律

- 认知分叉必须在所有分析之前执行，不得跳过
- 如果发现用户/市场混为一谈，必须明确指出
- 跨赛道比较时，必须先确认比较的是同一"世界"的命题
