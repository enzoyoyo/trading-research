# Trading Laws · 交易纪律速查（源文精确版）

> 通用交易研究纪律；私人原始档案不随包发布。
> 这里只放**可直接执行的量化纪律**；方法论展开见各 method 文件与 `unified-research-framework.md`。

## 游资情绪（炒股养家 / Asking / 退学炒股 / 小群哥 / 复盘V2.0 共识）

### 情绪周期四阶段 → 决定仓位基调
| 阶段 | 盘面特征 | 策略 |
|---|---|---|
| 启动/酝酿期 | 涨停数增多、连板高度打开、试盘信号 | 轻仓试错（10-20%） |
| 发酵/加速/主升期 | 主线确立、梯队完整、龙头缩量加速 | 重仓出击，聚焦核心 |
| 高潮/分歧期 | 涨停炸裂但高位股巨震/烂板、筹码松动 | 去弱留强，准备分歧 |
| 退潮/冰点期 | 跌停剧增、高位股 A 杀、昨日溢价极低 | **只卖不买，空仓防御** |

铁律：「退潮期只卖不买，空仓是最高级的操作；情绪上升期敢于重仓押注。」

### 赢面–仓位对应表（五套 Agent 共用的量化风控核心）
| 赢面 | 仓位 |
|---|---|
| <60% | 空仓观望 |
| 60–70% | 小仓 10–20% |
| 70–80% | 中仓 20–40% |
| 80–90% | 大仓 40–60% |
| >90% | 满仓——但须满足：上涨空间 30–50% 且下行空间控制在 3–5% 以内 |

赢面 = 胜率 × 赔率的综合判断（市场情绪 + 板块强度 + 个股地位 + 政策消息多维）。

### 龙头三要素
最先涨停（身位优势）+ 封单最大（资金认可度）+ 带动性最强（上板即跟风）。盘子适中、股性活、有辨识度的人气股优先；回避大盘股和无量跟风「杂毛」。

### 暴利来源 & 买卖原则
- 暴利来源：**弱转强 / 分歧转一致 / 预期差**。
- 买入机会，卖出风险：买在「机会出现」（龙头首板、强势股恐慌低吸、弱转强确认），卖在「风险出现」（龙头走弱、板块退潮、逻辑证伪）。
- 忘掉成本价：永不止损永不止盈 ≠ 不卖，而是卖出只因机会消失/风险出现，与盈亏无关；卖出后再现买点可毫不犹豫买回。
- 半仓试探：首次出击先半仓，**当天涨停**次日加满；当天不涨停次日择高点先出。只有半仓股迅速盈利才动用另半仓。
- 止损线：单笔 4–5% 无条件止损；有效跌破 5 日线离场。
- 行为纪律（退学炒股「小明」）：计划你的交易，交易你的计划；盘中只执行不决策；空仓是主动状态。

### 弱市操作分层
盘面弱→资金抱团白马；盘面稳→抱团题材；盘面强→猛干龙头（狙击法）。弱市只做「守株待兔」超跌反弹且 ≤10% 仓位。

## 威科夫量价
三大定律：供求 / 因果（盘整规模决定后续幅度）/ **努力与结果（核心）**。
- 价涨量增 = 趋势健康；价涨量缩 = 背离（上涨无力，反转首要信号）。
- 价跌量增 = 下跌有力；价跌量缩 = 下跌乏力，可能近底。
- 周期：吸筹(SC→AR→ST→Spring) → 上涨 → 派筹(BC→AR→ST→UT) → 下跌。
- 等关键位放量确认，绝不提前赌突破/反转。恐慌放量找买点，狂热放量找卖点。

## 利弗莫尔趋势
顺最小阻力路线（趋势第一）；总体市场大趋势决定个股；试探仓验证、正确加仓、错误快速止损；关键点突破才确认；不在噪音里频繁交易。

## 华源叙事 / 财报验证
- 给**叙事**估值，不给故事估值：PE = f(天花板高度 m, 折现率 r)，m = 终局利润 / 当前利润；与短期增速无必然关系。
- 折现率基准：A 股 ~10%；成长股牛市可下探 7%、防御性资产 6.7%；美股对标可用 8%。
- 反景气度：禁止「因增速高/边际改善/超预期」买入。景气度陷阱 = 增速高但天花板降（资产周转率下滑）。
- 财报是验证工具不是决策源头：**资产负债表为核心，利润表最不重要**。先排雷再找机会。
- 五大指标（看个股在全A的分位数趋势最重要）：①应收账款周转率（回款/收入质量）②(固定资产+无形资产)周转率（再投资质量/跑冒滴漏）③营运净资本占比（产业链地位，龙头应低/下降）④经营现金流净额/总资产（真实盈利）⑤一致预期 vs 实际（商业模式稳定性）。
- 两大一致性检验：财报内在逻辑自洽（如周转率↓不应伴毛利率↑）+ 财报画像与估值叙事匹配。

## 历史会押韵吗 / 杠铃 / A股拍卖机制
- A 股限制做空 → **拍卖机制**（股价由最乐观资金决定），非对冲机制。流动性泛滥时「天花板算不清」（朦胧美）的票弹性最大。
- 横着拔估值 = 基本面驱动（Alpha）；竖着拔估值 = 流动性驱动（Beta，注意 A 型暴跌风险）。
- 杠铃：左端极致成长（展望期买叙事最宏大的票）+ 右端确定性红利（天花板极低，只要不下滑就是超预期）；**规避中间地带**。
- 贝叶斯沙盘：P(逻辑兑现)=P(A1)→P(B|A)→P(C|AB)…，提前设想各情形对应点位，信号出现即执行；避免长链条「福尔摩斯推票」。

## 因子 / 组合
- 统一视角：E[R]=α+β'λ。因子两条件：驱动共同运动 + 长期被定价正收益。简约 3–5 个独立因子。
- 用于中线/多标的排序、组合风险、风格轮动；**不用于编造短线买点**。每个因子必须有经济含义（风险补偿或错误定价）。
- 工具：排序法、Fama-MacBeth（Newey-West 调整）、GRS 检验；组合做行业/市值中性化。

## 永久红线
- 不承诺收益；不替用户下单；不编造价格/财报/资金流。
- 数据缺口、账户缺口、期权墙缺口必须明说。
- 制度不乱迁移：A 股涨跌停/连板/龙虎榜不套美/港；美股 guidance/SEC/Gamma 不套 A 股。
- 回撤自检（Frank 2026-06-24）：组合单日回撤经常 >10%、或最大回撤 >30%，说明仓位结构不适合投机交易——该结论优先于任何「行情要来了」的判断；正确动作是降杠杆/定投宽基，不是找下一个更猛的票。
